# 卸载与回退（1.0.0）

卸载不会删除你的聊天、账本或记忆——它们存在聊天文件里，和插件无关。按下面的顺序做，以后重装或回到 v1.1 都能接着用。

## 1. 先备份（推荐）

1. 打开要保留的诸天聊天 → 终端 → 设置 → 账本与存档 →「导出 / 导入存档」→「导出存档文件」。
   每个聊天导出一次；文件不含 API Key。
2. 如果在用独立 API，把「连接」页的接口地址和模型记下来（密钥不会被导出，重装后需要重新填写）。

## 2. 解绑世界书

- 设置 → 提示词与世界书 →「一键解绑世界书」（或「世界书安装 / 绑定 / 解绑…」里的「一键解绑全部」）：把“诸天万界最强系统”世界书从角色卡、全局世界书和当前聊天上解绑（不删除世界书）。
- SillyTavern 1.17 及以上在「停用」插件时会自动解绑一次；1.16 没有这个钩子，需要手动解绑。
- 不想保留世界书时，在酒馆「世界信息」里删除 `诸天万界最强系统`（以及 `诸天万界最强系统-备份-*` 备份）。

## 3. 回到 v1.1（可选）

如果之前用过「一键接管旧版」：设置 → 诊断与维护 → 兼容与维护 →「恢复旧版」，会重新启用当时停用的 4 个正则和酒馆助手脚本
（只处理接管时记录过的项）。终端打不开时，在「扩展」设置抽屉里点「紧急恢复旧版」。

## 4. 删除插件

「扩展 → 管理扩展」→ 找到「诸天 · 莉莉丝契约终端」→ 删除，然后刷新网页。

删除后仍然留下的数据（都不影响酒馆运行）：

| 数据 | 位置 | 怎么清理 |
|---|---|---|
| 诸天账本、记忆、私聊记录 | 各聊天的 `chatMetadata.variables` | 留着可以随时重装继续；不需要时删除对应聊天 |
| 账本备份、结构版本、凭据 | 各聊天的 `chatMetadata.zhutianCovenantTerminal` | 同上 |
| 插件设置、莉莉丝 API 配置（含密钥） | 酒馆 `settings.json` 里的 `extension_settings.zhutian-covenant-terminal` | 不再使用时，在酒馆数据目录的 `settings.json` 里删除这一项（先关掉酒馆）；或者在删除插件前到「连接」页清空密钥 |
| 状态栏 API 配置 | 全局变量 `诸天系统_API`、浏览器 `localStorage.sys_api_config` | 在酒馆变量面板删除；清除浏览器站点数据 |

## 5. 重装

重新安装本插件 → 打开原来的聊天，账本会自动接上。在新设备上：先打开（或新建）对应聊天，再用「导出 / 导入存档」导入之前导出的文件，
最后在「连接」页重新填写 API Key。

> 1.0 起账本带结构版本：用较新的插件写过的账本，在较旧的插件里会变成只读（不会被写坏），更新插件即可恢复写入。
