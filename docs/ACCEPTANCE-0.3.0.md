## 三、立绘

### AI 差分（1.16 / 1.17 / 1.18 / 1.19 结果完全一致）

- 8 张表情图全部加载，原版立绘隐藏。
- 点触 8 个部位时，AI 差分跟随原版表情时间线切换：

| 部位 | 时间线 |
| --- | --- |
| wing | smile → neutral |
| horn | surprised → pout → neutral |
| tail | surprised → shy → neutral |
| arm | wink → smile → neutral |
| thigh | smile → neutral |
| lower | pout → neutral |
| chest | smug → neutral |
| cheek | shy → neutral |

- 姿势“比心”：显示静止背景和姿势图，静止背景的 `animation-name` 为 `none`。
- 姿势“抱臂”（素材缺失）：返回 404，回落到表情组，缺失的图片不会保留显示状态。
- 切回 `rig` 后原版立绘恢复显示，差分图层被移除。
