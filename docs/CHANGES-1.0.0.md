# 1.0.0 更新说明

一次直接从 0.9.4 更到 1.0.0（按你的决定：不发中间版本和 rc，没有试玩期，只用模拟模型验收，最低仍支持 SillyTavern 1.16）。
方案与取舍见 [PLAN-1.0](PLAN-1.0.md) 第六节。

## 一、手机悬浮莉莉丝：抠图人物，不再是小卡片

- 用原版 v1.1 的分层立绘（`ZhuTianLilithLayers`：plate、wings、tail、body、表情补丁）合成整图，
  交给动漫人物分割模型 isnet-anime 得到人物蒙版，再和 body 图层自带的透明度取较小值，
  去掉背景、星光和头发外的紫雾；只取头到大腿上部，底部羽化渐隐。工具：`tools/lilith_float_cutout.py`。
- 素材：`assets/lilith/float/`（身体、左右翅膀、9 个表情补丁，共 12 张 WebP），坐标常量 `src/lilith-float-art.js`，
  来源与 sha256 见 `assets/lilith/float/PROVENANCE.md`。
- 悬浮层没有卡片背景和边框，只有贴着人物轮廓的投影和淡淡的紫色辉光；能点的区域是人物中间部分，不是整个矩形。
- 动起来：呼吸、上下浮动、两只翅膀各自绕翅根扇动，拖动时翅膀扇得更快、身体随拖动方向倾斜；
  平静表情下每 2.5–6 秒眨一次眼，说话时嘴巴开合；双击（戳）会换表情、跳一下并扇翅膀。
- 交互和 0.8.2–0.9.0 完全相同：单击打开终端、长按拖动、拖到边缘躲起来（露出一部分）、终端打开时停在下角、
  大小设置（55%–100%）。
- 修复：躲在边缘时她要说话（例如终端里的反应台词），会先探出来再说，气泡不再一半在屏幕外。

## 二、设置分层与搜索

- 设置页分三组：**常用**（直接显示）、**进阶设置**、**诊断与维护**（默认折叠，标题上写着有几项）。
  快捷键、提示词剥离、宏、世界书自动绑定、超时、触屏手势、Live2D、莉莉丝镜头 / 剧情台词、演出范围等约 20 项移进「进阶」；
  「高级 · 管理员」在进阶，「兼容与维护」在诊断。其他模块追加的设置段默认放进进阶。
- 顶部搜索框：按标题和说明过滤，多个词要同时匹配；匹配到折叠组里的项时自动展开，清空后自动收起；搜不到时显示提示。

## 三、导出 / 导入存档、账本结构版本、回滚

- **设置 → 账本与存档 → 导出 / 导入存档**（也可以输入 `/zt export`）：
  - 导出：一个 `诸天存档-年月日时分.json`，包含插件设置和当前聊天的诸天账本（聊天群、星图足迹都在账本里），
    可选记忆存档和莉莉丝私聊记录。**不含 API Key**：名字像 key / token / secret / password 的字段、
    `sk-…` / `Bearer …` 一类的值都会去掉，网址的查询参数也会截掉。手机上没弹出下载时可以「复制存档文本」。
  - 导入：选文件或粘贴文本，先显示“现在 → 导入后”（系统点、当前世界、背包、任务、聊天群成员、万界足迹、设置变化数）；
    确认后**先备份当前账本**，再写入并逐项读回核对；设置里本机已存的 API Key 不会被清空。
  - 文件格式有版本号；来自更新插件的文件、坏文件、别的 JSON 都会给出能看懂的拒绝原因。
- **账本结构版本**：记在 `chatMetadata.zhutianCovenantTerminal.ledgerSchema`（不在账本里，AI 看不到也改不到）。
  - 打开聊天时检查：旧账本（0.9.x 及以前写的，记为 0）先备份，再按迁移步骤修正类型（背包 / 任务库 / 万界足迹 / 系统点），标记为 1；
  - 由更新版本插件写过的账本：本插件所有写入都会拒绝并提示“只读，请更新插件”，不会写坏。
- **回滚**：「旧存档迁移 / 账本回滚」里点回滚时，回滚前的状态**总会**先备份并保留在列表里。
  以前这次备份在 90 秒内有过别的写入时会被合并掉，而确认框却说“会先备份”。备份列表里显示备份原因（导入前 / 回滚前 / 结构升级前）。

## 四、统一错误提示

- 新增 `src/errors.js`：失败提示统一为「发生了什么。账本：…。下一步：…。」
  - 写入前就被拦下的（聊天已切换、群聊、系统点不足、没填、Web Locks 不可用、只读账本）→「账本：没有改动」；
  - 超时、网络、5xx、格式解析失败（这些请求的费用失败时会退回）→「账本：没有改动（费用已退回）」；
  - 读回不一致 →「账本：可能已经写入」，并指向账本回滚；
  - 认不出的错误不写账本状态，不乱下结论。
- 用在：设置页的各个按钮、聊天群、迁移 / 世界书 / 立绘等弹窗、新手引导、一键接管 / 恢复旧版、`/zt` 命令的报错。

  - 当前状态和原因写在设置说明和「复制诊断信息」里。

## 七、玩家反馈补充（版本号仍是 1.0.0）

按 1.0.0 发布后的玩家反馈继续优化，没有升版本号。

### 1. 剧情里得到的功法 / 物品不再锁死在凡品（品阶鉴定）

- **原因**：原版 3.1 引擎在数据块「收录:功法名」没写 `[品阶]` 时一律按凡品入账；之后再写「收录:同名[仙品]」，
  因为功法已经存在而被忽略。角色卡、旧存档、其他来源的物品没有品级时也按凡品显示和回收。除了商城没有任何地方能再升。
- **新增「品阶鉴定」页**（设置 → 账本与存档 → 品阶鉴定；修行页、修行 · 熟练度页、背包页都有入口）：
  列出所有**不是系统给的**功法和物品（来源是收录、数据块、旧存档、角色卡、空白……）。商城、盲盒、熔炉、洞天、分身探宝、
  无限口袋、图鉴复刻、任务奖励、聊天群、自拟外挂、管理员给的不列出——那是系统自己判定的品阶。
  - **AI 鉴定**：按诸天统一标准（凡品＝凡人之物 / 凡俗武学，灵品＝武道宗师 / 超凡，仙品＝城市到大陆级，神品＝行星级以上）
    让模型给出「品阶 + 一句理由」。走「分功能 API → 品阶鉴定」，没单独设置就用默认接口。
  - **手动修正**：下拉选更高的品阶，确认后写入。
  - 只升不降，最高神品（鉴定不会给禁忌）。功法上限随品阶提高（凡 100 / 灵 500 / 仙 2000 / 神 10000），「圆满」标记清除；
    物品改品级后**回收价保持原来的**（防止改品阶刷回收），同名同品级的会合并。
  - 每次写入：一次加锁提交 + 读回核对；楼层快照同步修改（换页 / 重新生成不会撤回）；功法写进「功法记录」，条目上记下
    鉴定方式、原品阶和理由。
- **「收录:功法名[更高品阶]」可以更正剧情功法**：新数据块里对已有的非系统功法写更高品阶时自动升级（只升不降，系统给的
  功法不受影响）。这一条跟随它所在的楼层：换页 / 重新生成时随旧回复撤回，新回复重新判断。设置里可关。
- **提示 AI 写明品阶**：每轮一行提示（深度 4）——收录时写 `[品阶]`，按它本身的威力判断，不写会按凡品入账。设置里可关。

### 2. 分功能 API（每个调用模型的地方都能单独配置）

连接页（设置 → AI 接口设置）新增「分功能 API」折叠区，列出全部 11 处：商城进货、抽卡 / 盲盒、许愿、招募打手、
背包整理 / 万物熔炉、战力评估、品阶鉴定、诸天聊天群、莉莉丝私聊、莉莉丝自动记忆、莉莉丝工作台。
每一项可以选：**跟随默认**（和以前一样）/ **酒馆当前主 API** / **某个预设** / **单独配置**（点「用上面填写的」把表单里
的地址、密钥、模型存给这一项）。每行显示“现在用的是哪里”（只显示地址和模型，不显示密钥）。

- 原版代码不改：状态栏和莉莉丝仍按默认接口组装请求，插件在请求发出的地方（`th-bridge.generateRaw` 与莉莉丝的 fetch）
  按功能改到对应的地址、密钥和模型。状态栏的各个功能按原版的系统提示词区分；连接测试永远走默认。
- 出错时报错里会写明「（X 用的是预设「…」）」，方便判断是哪个接口坏了。
- 「复制诊断信息」多一行分功能 API 摘要（预设个数、哪些功能单独设置、最近一次用的是哪里），不含密钥。

### 3. 接口预设（不用再反复填公益站）

连接页顶部新增「接口预设」：下拉选择预设即可把地址 / 密钥 / 模型填进表单（再点保存即切换默认接口）；
下方输入预设名称后点「保存为预设」。**没输入名称时按钮是灰的，不能保存**；名称已存在时按钮变成「覆盖预设」；回车也能保存。
可删除预设（用到它的功能自动改回跟随默认）。最多 30 个。「酒馆当前主 API」不需要存成预设，在分功能里直接选。

- 预设和分功能设置存在酒馆的全局变量 `诸天系统_API路由` 里（和原来的默认接口放在一起），不进聊天文件、
  不进「导出存档」、不进诊断信息。

### 4. 一键关闭插件

设置 → 常用 →「插件开关」→「一键关闭插件」。先弹确认框（说明账本和设置都保留、世界书会自动解绑、怎么重新开启），
确认后调用酒馆自己的 `disableExtension`——和「扩展 → 管理扩展」里关掉开关完全一样，页面刷新后插件停用。
重新开启：酒馆顶栏「扩展」→「管理扩展」→ 打开「诸天契约终端」。酒馆没开放这个接口时，提示手动操作的位置。

### 5. 关闭悬浮莉莉丝

- 拖动悬浮莉莉丝时，屏幕底部中间出现「拖到这里关闭悬浮窗」；拖上去松手 → 确认框。电脑上也可以右键她：
  打开诸天终端 / 藏到屏幕边 / 关闭悬浮窗。
- 确认框和关闭后的提示都写明：**关闭后可以从酒馆「扩展」面板（顶栏积木图标）→「诸天终端」→「打开诸天终端」重新进入控制台**；
  原版唤醒按钮也会回来。
- 让她回来：扩展面板里新增「显示悬浮莉莉丝」按钮，或终端「设置 → 莉莉丝 → 悬浮莉莉丝」。

### 6. 顺带修复

- 注入的提示词（修行实效、聊天群、外挂、品阶）在切换 / 重新加载聊天后可能丢失：酒馆加载聊天时会清空所有扩展提示，
  插件以前只在内容变化时才重新注入。现在会核对酒馆里实际还在不在，不在就补上。
- **手机上有几个浮层跑到了屏幕上方外面**（看不见）：酒馆的手机布局给 `<html>` 加了变换且高度为 0，用 `bottom:` 定位的固定浮层
  因此被放到屏幕顶部之外。受影响的有：本轮新加的「拖到这里关闭悬浮窗」、终端关着时在聊天页弹出的**演出卡片**（0.7.0 起，
  电脑上正常、手机上一直看不见）、旧酒馆助手占用时的**备用入口按钮**。现在都改为按屏幕高度从上往下定位，电脑上位置不变。

### 7. 测试

- 新增 `tests/v100-feedback.test.js`（19 项纯逻辑）与 `tests/native_v100_feedback.py`（44 项浏览器验收，模拟模型；含手机真实触摸长按拖到底部关闭），
  模拟模型增加品阶鉴定的回答。详见 `docs/ACCEPTANCE-1.0.0.md`「玩家反馈补充」。
