## 发现并修复

### 账本与人物

- 同名人物明确改为另一个世界，原逻辑仍沿用旧ID：新增真实Bridge和单元反例，现保留两人及各自好感。
- 鉴定等待模型、导入等待备份、回滚等待备份期间切聊天，缺少全程目标捕获：现在生成前/备份前固定身份，提交前及锁内校验；新增真实选择另一角色的测试，不只是替换身份函数。
- 整体导入/回滚误走增量羁绊同步，可能混入导入前目标：明确区分整账本替换和增量更新。
- 备用原生结算硬编码schema1且未拒绝未来版本：改用当前schema2并检查只读边界。
- 导入预览期间切聊天、备份后账本变化、重复导入、结构版本保存未核实等边界补保护。

### 商品、收纳和鉴定

- 禁忌购买的 `Number(undefined/NaN/非法文本) < 1` 为false，可能漏过资格判断：两条购买路径统一检查安全整数及至少1筹码。
- 暂存待鉴定未保留用户勾选的“明确新获得另一份”，后续无法追加：现在保留该确认标记，并继续用来源凭据防重复。
- 再鉴定使用当前旅行世界映射，而不是物品来源世界：候选带原世界品阶与来源世界，提示使用对应映射。
- 购买等待期间内容已变但名称/价格未变：提交时比较整条候选快照，变化则拒写。

### 世界书、API、导出和界面

- 同名内置条目有多份时Map合并可能丢掉用户副本：只更新第一份，其余重复条目原样保留。
- 世界书升级增加重复提交防护和提交前变化检查；该次修补曾误影响普通模块开关，扩展浏览器回归抓到 `readDisk is not defined`，已修复并补专门单测，再跑完整模块/慢API套件。
- 旧连接测试把用户显式1000上限强提4096：公共/功能显式上限现在统一优先，含走酒馆主API的助手路径。
- 泛用敏感字段清理误删记忆记录语义 `key`，以及特殊字面世界名 `__proto__`：语义字段和普通数据键保持，真正API配置Key继续清除，避免设置对象原型。
- 新iframe增强器把旧document闭包积存在全局清理列表：改成活动frame资源域，重建时清旧域、pagehide/停用时确定性释放。
