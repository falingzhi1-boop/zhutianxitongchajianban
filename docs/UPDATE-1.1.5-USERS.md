# 诸天终端 1.1.5 更新报告

本次对比 **1.1.3 → 1.1.5-r1**，包含 1.1.4、1.1.5 和 r1 修订。已经在用 1.1.4 的朋友，可以重点看人设、功能开关、世界书召唤和 r1 修复。

这次可以给自己的系统换人设，把不用的功能关掉，也能把世界书里的角色请进聊天群。群聊增加了重roll和消息管理，存档核对与思维链处理也做了修正。

## 系统助手可以换人设了

默认仍是莉莉丝，也可以换成带编号的系统光球，或者自己设定一个系统助手。

自定义支持名字、对宿主的称呼、性格、说话方式和头像；想改得更彻底，还能分别填写剧情规则与私聊人设。保存后，界面、系统台词识别和后续助手请求跟着换，随时可以切回莉莉丝。

换人设不会重写旧聊天、旧私聊，也不会改你的世界书原文件。其他人设使用圆形头像，莉莉丝的分层立绘与触摸动作仍只属于莉莉丝。

入口：**设置 → 上手 → 系统助手人设**。

## 不用的功能可以单独关闭

新增统一的功能开关页，按系统助手、聊天楼层与数据块、剧情提示、聊天群、界面与操作分组，共37项，另有页面显示和按聊天设置的入口。

想关语音框、自动补记、自动闲聊、触摸、快捷键或整个聊天群，都可以分别选择。不常用的页面也能从导航里隐藏。关闭通常保留原有数据，需要时再打开。

关闭整个聊天群时，正文群摘要、自动闲聊和降临计时一起停；r1还修正了关闭后群联动规则仍发给正文AI的问题。隐藏一个页面与关闭整个模块有不同作用，详细说明书已逐项列明。

入口：**设置 → 上手 → 功能开关**。系统助手窗口开关需要刷新后生效。

## 世界书里的角色可以进入聊天群

在群员页选一本已有世界书，按角色名或关键词查找，再召唤为候选人、确认邀请入群。★标记表示当前聊天启用的世界书，方便找现有角色。

召唤来的群员会记下来源条目，群聊和私聊时可带上人物资料与相关背景。开启对应联动后，角色在正文里出场时还能收到最近群聊、私聊、赠礼和好感的摘要，帮助衔接群内互动。

查找只读资料；召唤招募每次100系统点，失败按流程退回；邀请入群另按实力档收费。插件不会把群聊历史写进原世界书。

入口：**聊天群 → 群员 → 从世界书召唤**。

## 群聊可以重来 也可以管理消息

1.1.4增加了「↻ 重roll」：保留你的输入，重新生成最近一轮群员回复。新回复成功后才替换旧轮，失败时旧回复保留。

「🗑 管理」可以逐条删除普通消息。未领红包或赠礼可确认作废；已经抢到的红包、已经领到的赠礼，以及自己已付费发出的红包受保护，不能靠删消息或重roll反复领收益。

群务里新增最少和最多发言人数、每条字数、最近消息数量、输出上限。独立接口检测到回复截断时会提示，方便调整后重roll。旧版消息没有轮次记录，不能追溯重roll。

## 修正存档误冻结 记忆格式和思维链处理

- **减少存档误冻结**：核对写入时聚焦本次改动，避免无关变量变化被误判。真正状态不明时仍会保护账本。
- **新增核对并解冻入口**：服务器与页面一致时可解冻；不一致时先列差异，再决定重载。
- **记忆键自动清洗**：处理部分空格、全角、特殊字符和重复键，不再因此轻易整批整理失败。
- **修正思维链草稿误识别**：避免思考里的未完成数据块吞掉正文、结束标签或正式数据块；思考里的台词不再误画成系统语音卡。
- **新增最新楼层检查**：可以看这一层有没有被插件改写、如何渲染，以及各扩展注入的提示位置，反馈问题更容易定位。

## r1另外修了五处问题

- 群聊或群员私聊读取世界书时也立即进入忙碌状态，避免连点和自动闲聊撞出两轮请求。
- 关闭聊天群后，本轮正文不再收到内置群联动条目；重新开启后恢复。
- 用户刚发的正文第一次提到群员时，及时刷新互动记忆，减少晚一轮才衔接的情况。
- 换人设后加入旧称呼对照，减少旧“莉莉丝”称呼把助手拉回原人设。
- 自定义名字至少两个字，并修正带特殊字符的名字可能影响语音识别的问题。

## 如何更新和查说明书

先在 **设置 → 账本与存档 → 导出 / 导入存档** 备份。然后在酒馆 **扩展 → 管理扩展** 找到本插件，更新完成后刷新网页。仅刷新不会下载新代码。

扩展显示版本1.1.5；复制诊断信息可核对修订1.1.5-r1。旧聊天数据继续沿用，已有设置保持原选择；默认人设仍是莉莉丝。
