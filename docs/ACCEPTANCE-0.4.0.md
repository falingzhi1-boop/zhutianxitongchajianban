**1.19 上 `native_ledger` 的说明**：
- **问题**：第一轮矩阵里，它和依赖它的 `native_ledger_guards` 在 1.19 上失败了。1.19 的数据目录不是全新的，而 1.16–1.18 是全新安装。
- **原因**：一个测试时序竞争。脚本写入的夹具楼层带有 `<ZhuTianPanel>`；0.3.0 起，原生状态栏是剧情结算引擎，它会在测试切换到“仅终端”模式之前，抢先把这个面板结算掉。
- **修复**：测试改为页面一就绪、写入夹具之前就进入“仅终端”模式；每次重载后也立即进入。插件代码没有改动。
- **复验**：修复后，在全新的 1.19 上连跑两轮全部套件，第二轮就是非全新数据目录的情况。结果见文末“最终复验”。

## `native_replace040.py` 覆盖项（70 项，四个版本全部通过）

1. **渲染**：
   - 最新楼层（深度 0）显示完整状态栏 iframe；深度 2 和 4 的楼层显示精简卡。
   - 每个 AI 楼层都有语音卡，且不显示情绪词、支持行内 Markdown、按语气切换头像。
   - 界面上不会露出原始面板或槽位文本。
   - 显示侧的宏已替换。
   - 语音美化开关往返正常：关闭后是纯文本。
   - 精简卡能展开为完整状态栏；关闭精简显示后改为“历史”按钮。
2. **世界书**：
   - 打开诸天聊天时自动安装（35 条）并绑定。
   - 64k 上下文下，预算足够容纳常驻规则。
   - 提示词里包含常驻规则原文，其中的宏已替换为账本值。
3. **生成**：

   - 提示词里不再残留原始 `{{get_chat_variable}}`。

   - 流式回复后显示状态栏和 2 张语音卡。

4. **API 中心**：

5. **状态栏 AI**：

## 其他实机检查（1.19）

- **AI 姿势**：比心、抱臂、侧坐三种姿势都显示在莉莉丝窗口里。
  - 背景是静止的原版 `plate`，动画为 `none`。
  - 人物上下没有空白。
- **可选的终端入口按钮**：在 1500×1000 视口下，原来会与莉莉丝入口重叠（点击被拦截）。现在停靠在入口正上方 10px 处，入口被拖动或窗口缩放后也会跟随（1.18、1.19）。

## 已知边界（未验证或次要）

- **真实模型**：未验证。以上 AI 链路只用模拟模型跑过；模型的输出格式遵从度会直接影响原版解析器的结果。
- **主 API 模式下的温度**：莉莉丝记录员请求用的是 ST 当前预设的温度（验收时为 1），不是固定值。
- **未逐项点击**：
  - 十连和自定义次数抽卡；
  - 外挂和神通里不调用模型的支付类动作；
  - 触觉反馈（无头浏览器里无法验证）。
- **Live2D**：0.4.0 没有改动，沿用 0.3.0 的验收结果。
