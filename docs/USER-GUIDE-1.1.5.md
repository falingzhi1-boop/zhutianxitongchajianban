# 诸天终端 1.1.5 详细用户说明书

适用修订 **1.1.5-r1** · 对照代码版本 **8bbb23d** · 整理日期 **2026年10月10日**

这份说明书供诸天终端用户查操作：每个页面做什么，按钮点下去会怎样，哪些动作扣系统点、请求模型、修改存档，失败时如何处理。第1至19章用于快速查阅，第20至40章按操作补充每类按钮、输入项、保存范围与限制。

**第一次使用或更新后，先导出当前聊天存档。** AI相关功能按当前模型接口执行，服务商可能计费；真实模型、人设扮演、实体手机和部分原版支付操作仍有未验证范围，具体见第17、20和40章。

- [本次更新报告](UPDATE-1.1.5-USERS.md)
- [可搜索网页版文件](USER-GUIDE-1.1.5.html)：点进文件页后下载，用浏览器打开；这是离线阅读文件，GitHub文件页本身不会运行其中的搜索。
- 按钮上的人物名、商品名、金额和数字随存档变化，同类动作按一次说明，实际收费以点击前的本页报价为准。
- 手机阅读网页版时，较宽的表格可以左右滑动，查看右侧的费用、条件或限制。

## 1. 快速上手

### 1.1 安装与更新

1. SillyTavern →「扩展」→「安装扩展」，粘贴：`https://github.com/falingzhi1-boop/zhutianxitongchajianban`
2. 安装完刷新网页，打开一个**单角色**聊天（酒馆群聊不支持）。
3. 需要 SillyTavern 1.16 或更高（项目验收材料记录 1.16.0 / 1.17.0 / 1.18.0 / 1.19.0；不代表本次已重测所有宿主）。不需要酒馆助手，也不需要导入正则。
4. **更新**：「扩展 → 管理扩展」里找到「诸天 · 莉莉丝契约终端」，点更新，然后刷新网页。只刷新网页不会下载新代码。
5. **卸载**：先导出存档、解绑世界书，再删除扩展（详见 `docs/UNINSTALL.md`）。

### 1.2 第一次使用（新手引导）

第一次打开终端会出现「新手引导」（左侧「引导」页），一共三步，每步完成会打 ✓：

| 步骤 | 做什么 | 按钮 |
|---|---|---|
| 1 导入或更新世界书 | 安装并绑定「诸天万界最强系统」世界书（诸天存档会自动做） | 自动完成 |
| 2 设置 AI 接口 | 填独立接口，或者直接用酒馆的主 API | 「修改」→ 跳到「连接」页 |
| 3 在当前聊天启用 | 给当前聊天建账本 | 「在当前聊天启用」 |

- 「跳过引导」：不再显示引导。
- 「先这样，以后再说」：当前实现也记录为跳过，以后从设置手动再开。
- 随时可以在 设置 → 上手 →「新手引导 ›」重新打开。

### 1.3 从旧版 v1.1（世界书 + 正则 + 酒馆助手脚本）迁移

1. 装好本插件，打开诸天聊天。插件会自动安装并绑定外挂世界书，已经存在的不覆盖。
2. 设置 → 兼容与维护 →「一键接管旧版」：停用旧的 4 个正则和旧的酒馆助手脚本（只停用、不删除），保存后自动刷新。
3. 想回到旧版：「恢复旧版」。终端打不开时，扩展设置抽屉里还有「紧急恢复旧版」。
4. 「兼容诊断」提示「世界书预算不足」时，点「一键调整」（酒馆默认只给世界书 25% 的上下文）。
5. 旧聊天的账本：设置 → 账本与存档 →「旧存档迁移 / 账本回滚 ›」。

## 2. 怎么打开终端

| 入口 | 用法 |
|---|---|
| 悬浮莉莉丝（手机 / 触屏默认） | **点一下**：打开终端（终端已打开时只说话）。**双击**：戳她一下，会有台词和表情。**长按拖动**（电脑上直接拖）：移动位置，拖到屏幕左右边缘会藏起来，只露一点，点露出的部分就会出来。**拖到屏幕底部**：出现「换成头像」和「关闭悬浮窗」两个目标。 |
| 头像悬浮窗（电脑默认） | 点头像打开终端。拖到底部同样可以换成悬浮莉莉丝或关闭。 |
| 快捷键（电脑） | `Alt+Z` / `Alt+X` 打开或关闭终端，`Alt+S` 打开总览。可在设置里关掉。 |
| 斜杠命令 | 在聊天输入框输入 `/zt open`（见第 15 章）。 |
| 楼层小标签 | 点聊天楼层下方的「✧ 系统已记录 … 查看 ›」，会打开终端并定位到这一层的数据。 |
| 输入框上方账本速览（HUD） | 显示 系统点 / 当前世界 / 任务，点它打开终端。 |

关掉悬浮窗以后，可以在 设置 → 莉莉丝 →「悬浮窗」里选回来。

## 3. 终端窗口

### 3.1 标题栏

| 按钮 | 用途 |
|---|---|
| 版本号（如 1.1.4） | 当前插件版本。 |
| ✥ 拖动窗口 | 按住拖动终端窗口（浮动窗口模式）。窗口右下角可以拖动调整大小。 |
| 全屏 / 浮窗 | 在全屏和浮动窗口之间切换（手机上两种布局都有这个按钮）。 |
| ↻ 窗口复位 | 把终端窗口的位置和大小恢复成默认。 |
| — 收起 | 收起终端（再次点头像 / 悬浮莉莉丝打开）。 |
| × | 关闭终端。只关终端，不影响悬浮窗。 |

手机上可以用返回手势关闭终端（设置里可关）；点终端外部是否关闭，由设置「点击终端外部时关闭」决定。

### 3.2 顶部数据栏

依次显示：**当前世界**（带世界类型标签，比如「玉简」=仙侠）、**系统点**、五种专属资源（**天命印记 / 血脉结晶 / 因果筹码 / 名望 / 岁月沉淀**）、**商城等级**。数据来自当前聊天的账本，写入成功后自动刷新。

### 3.3 左侧导航

| 分组 | 页面 |
|---|---|
| 系统 | 总览、任务、羁绊、修行 |
| 交易 | 商城、背包、操作日志、商品定制、剧情收纳 |
| 能力 | 外挂、自拟、神通 |
| 图谱 | 事件线、羁绊图、星图、能力树 |
| 万界 | 聊天群 |
| 莉莉丝 | 工作台、记忆、规则 |
| 终端 | 引导、连接、状态、设置、说明书 |

> 1.1.5：设置 →「功能开关」可以把不用的页面从导航里拿掉（总览、设置、连接一直保留）；导航分组「莉莉丝」在换人设后显示人设的名字。

终端底部有一行莉莉丝的提示（比如「聊天切换；仅使用当前聊天的记忆」）。

## 4. 系统

### 4.1 总览

- **基础概览**：宿主状态、绑定目标、当前任务、资源等（原版状态栏第 1 页）。
- 「AI 可见数据（诸天系统.实时数据）」：展开后能看到下一轮会告诉 AI 的那份数据；「复制」复制它。
- 「查看星图 ›」：跳到 图谱 → 星图。

### 4.2 任务

- **任务日志**，下拉框可以筛选：进行中 / 待接取、长期任务、短期任务、已归档、全部任务。
- 点一条任务可以看详情和进度；「上一页 / 下一页」翻页。
- 任务由 AI 在数据块里发布和更新，也可以来自工作台、聊天群「求助」。
- 「查看事件线 ›」：跳到 图谱 → 事件线。

### 4.3 羁绊

- **多人羁绊**：显示本世界和所有世界的人物（好感度、关系、黑化 / 悔意等）。
- 搜索框：按人物、世界、关系搜索。
- 筛选：本世界 / 全部 / 恋人·攻略 / 打手 / 群友（数字是人数）。
- 「补录人物 / 更新多人关系（不扣费、不发奖）」：填 姓名、来源世界（同名人物靠世界区分）、关系、好感度（0–100）、说明，然后点「保存人物」。用来补上 AI 漏记的人物。
- 聊天群群员默认**不进**羁绊；要加进来，在 聊天群 → 群员 点「拉入羁绊」。

### 4.4 修行

- **万象修行**：选功法和修炼时长（一个时辰 / 一天 / 七天 / 一个月 / 一年 / 十年），点「写入输入框」，会生成一句修炼指令放进聊天输入框，由你发送。
- 功法熟练度阶段：未入门 → 熟练 → 精通 → 宗师 → 入道。可以打开「告诉 AI 每门功法当前阶段的真实效果」：熟练消耗 −30%，精通威力 +100%，宗师有专属奥义，入道无消耗瞬发。
- 「品阶鉴定 ›」：剧情里得到、却被记成凡品的功法可以重新鉴定（见 5.6）。
- 「阶段效果与来源 ›」：查看每门功法的阶段效果和来源。
- 「剧情物品 / 功法收纳」：跳到「剧情收纳」。

## 5. 交易

### 5.1 商城

顶部有 5 个分区按钮：

| 分区 | 用途 |
|---|---|
| **万界盲盒** | 「单抽 · 1万」「十连 · 10万」「五十连 · 50万」；输入数字后点「自定义抽数」。神品 1000 抽保底。旁边可以切换抽卡模式：**经典折叠**（默认，整次一起结算，≥50 抽时凡品合成一行，≥100 抽时灵品也合成一行，折叠的部分只计数、不生成）或**十抽一结算**。 |
| **待处理奖励** | 抽到但还没领取 / 处理的奖励。 |
| **万能许愿** | 在「输入愿望...」里写愿望，点「询价」，AI 定价并判定，确认后扣点。 |
| **商城库存** | 「一键进货 · 500 系统点」让 AI 按定制进一批货，然后购买。「商品定制 / 近期避重」跳到商品定制页。 |
| **物品回收** | 把背包物品卖回系统换系统点。 |

所有扣点 / 发奖都是**加锁写入并读回核对**的。读回不一致时会冻结账本，见第 13 章。

### 5.2 背包

- **随身行囊**：所有物品，按分类显示，可以使用、查看。
- 「AI 背包整理（重新分类 + 补全功能简介）」：让 AI 整理分类、补写简介。
- 「品阶鉴定 ›」：重新判定剧情物品的品阶。
- 「剧情物品 / 功法收纳」：跳到「剧情收纳」。

### 5.3 操作日志

本机记录的操作（购买、抽卡、许愿……）。可以勾选、分类、预览。刷新后默认不放进正文；真正的账本凭据会保留。

### 5.4 商品定制

- **抽卡模式**：经典折叠（默认）/ 十抽一结算。
- **商店进货定制**：
  - 来源：诸天混合 / 当前世界 / 指定世界·作品（指定时填原作名）；
  - 题材：科幻、都市、武侠、奇幻、历史、日常、动漫游戏、修仙玄幻；
  - 类别：消耗品、武器、装备、服装、素材、其他；
  - 用途：探索、生活、治疗、战斗、建造、情报；
  - 「排除项」：用逗号分隔，填不想再出现的物品或题材；
  - 「允许原创」；
  - 重复策略：近期避重（含相似效果）/ 允许常用消耗品重复；
  - 改完点「保存商店配置」。
- **盲盒奖励定制**：选项同上，改完点「保存盲盒配置」。

### 5.5 剧情收纳

把正文里得到的东西正式登记进背包 / 功法库，**不扣点**：

1. 填「起始楼层」「结束楼层」和「来源世界」。
2. 可选：勾「附带当前角色卡描述（最多 6000 字）」，选一本世界书作为参考，或者在「映射」里填明确的对应关系（JSON）。
3. 点「提取候选」，AI 列出候选物品和功法，并附带证据原文。
4. 勾选要收纳的条目，确认后入库。
5. 原世界的品阶会保留；判断不了的标为「待鉴定」。「待鉴定与收纳来源」里可以查看。

### 5.6 品阶鉴定

剧情里得到的功法 / 物品默认按凡品入账。在这里可以让 AI 鉴定，也可以手动修正，**只升不降**。相关设置在 设置 →「品阶鉴定」。

## 6. 能力

### 6.1 外挂（外挂工坊）

顶部分区：

| 外挂 | 用法 |
|---|---|
| **无限口袋** | 从背包选物品点「存入」；填数量后点「取出 ×N 个」；「清空」。 |
| **诸天打手** | 填角色名（如：宇智波鼬）和出处（可选），点「召唤」，AI 生成招募卡，整理并登记打手卡；与聊天群的分档入群费不是同一套流程，详见第 25 章。 |
| **洞察之眼** | 选目标实力档和情报深度（表层档案 / 隐秘情报 / 底牌弱点），点「支付并洞察」。 |
| **分身派遣** | 选任务（打工赚点 / 代为修炼 / 探宝寻缘）和轮数（3 / 5 / 10），点「支付并派出」。 |
| **随身洞天** | 选品阶，点「种下灵种」；「扩建灵田」。 |
| **万物熔炉** | 选背包物品，点「开炉熔炼」。 |
| **操作记录** | 外挂的使用记录。 |

- 「＋ 自拟外挂」「外挂管理 ›」：跳到「自拟」页。

### 6.2 自拟（外挂管理）

- 「‹ 返回外挂工坊」。
- **强力模块**：对应世界书条目，对所有聊天生效，用开关启停。
- **原版外挂**：只对本聊天生效的开关。
- **自拟外挂**：自己写外挂，存在本机外挂库里，开关只影响本聊天。
  - 「导出 .json」「导入 .json」：分享或备份外挂库。
  - **新建**：填名称、品阶（凡品 ~ 禁忌）、类型（被动 / 主动 / 每日次数）、每日次数、代价（无 / 系统点 / 专属资源）和资源种类、每次消耗数量、冷却回合、规则说明（写给 AI 看：效果、限制、副作用），然后点「加入外挂库」。
- **发动记录**：本聊天最近 30 次发动。

### 6.3 神通

| 分区 | 用法 |
|---|---|
| **实力设置** | 设置宿主和对手的实力档（1 档凡人顶尖 ~ 8 档概念 / 全能）。「这两个档位有什么用？」展开有说明。「AI 评估实力档」让 AI 根据剧情评估。 |
| **图鉴复刻** | 复刻某个能力，按档位付费，点「支付并复刻」。 |
| **状态改写** | 选改写类型（伤病痊愈、复活、对敌施加负面状态等），填对象，点「支付并改写」。 |
| **言灵改字** | 选改字程度（无害化 / 小反转 / 结果反转），填要改的那句话，点「支付并改字」。 |
| **神通记录** | 使用记录。 |

- 「查看能力树 ›」：跳到 图谱 → 能力树。

## 7. 图谱

| 页面 | 内容 |
|---|---|
| **事件线** | 任务、结算凭据、万界足迹按时间排成一条线。「本次会话的演出」：只在账本读回确认后播放，被回滚的会标为「未入账」；点「查看」可以重看。 |
| **羁绊图** | 恋爱目标、打手、群员的关系图。点人物可以跳到羁绊页；群员可以「拉入羁绊」。 |
| **星图** | 到访过的世界。「记录穿越」：填世界名、选类型（自动 / 仙侠 / 赛博 / 诡异 / 都市 / 西幻 / 末世 / 其他），点「记录穿越」，会写入 当前世界 / 世界类型 / 万界足迹，界面主题跟着切换。 |
| **能力树** | 实力档、功法、神通、外挂汇总成一棵树。 |

## 8. 万界：聊天群

诸天万界聊天群是终端里的一个跨世界群聊，**和酒馆的群聊功能无关**。顶部写着群名、群员数、商城等级和红包上限（红包品阶不会超过商城等级）。

分 4 个子页：**聊天 / 群员 / 集市 / 群务**。

### 8.1 聊天

- 在输入框写消息，按 Enter 或点「发送」。群员会按话题回复，每次几个人发言、每条多长，在 群务 →「群聊生成」里设置。
- 工具栏：

| 按钮 | 用途 |
|---|---|
| 🧧 发红包 | 你给群里发红包（系统点或物品），群员抢。 |
| 签到 | 每天一次，奖励 = 100 × 连签天数（最多 7）+ 10 × 群员数。 |
| 求助 | 写下要求助的事，某位群员会把它变成一个任务，发到任务页（状态「待接取」）。 |
| 群直播 | 某位群员直播自己世界此刻正在发生的事。 |
| **↻ 重roll（1.1.4）** | 重新生成**最近一轮**群员发言，见下文。 |
| **🗑 管理（1.1.4）** | 打开后每条消息旁边出现 🗑，可以逐条删除；点「✓ 完成」退出。 |
| 自动闲聊（勾选） | 主聊天每过几轮，群里自动聊一轮（通常最多 3 人，下限设置更高时可超过），间隔在群务里设置。 |

- 群员的消息里可能带**红包**（点「抢」）或**赠礼**（点「领取」，入背包）。领取后会显示「已领取」。

#### ↻ 重roll（1.1.4）

- 作用对象是最近一轮：可以是你发消息后的回复，也可以是一次自动闲聊。输入不变，你的发言保留。
- 会先弹窗确认，然后发请求。**新回复到达后**才替换旧的一轮；请求失败或超时，旧的一轮原样保留。
- **不能重roll 的情况**（按钮会提示原因）：这一轮的红包你已经抢了，或者赠礼你已经领了。
- 可以重roll 时，会一起撤回：没抢的红包、没领的赠礼、今日已收红包数、红包节奏、这一轮用掉的禁言轮数。
- 1.1.3 及以前的消息没有轮次记录，不能重roll，但可以逐条删除。

#### 🗑 删除（1.1.4）

- 普通消息、系统提示、你自己的发言：直接删除。
- **不能删**：你抢过的红包、你自己发的红包（已扣账）、你领过的赠礼。
- 没抢的红包 / 没领的赠礼：确认后和消息一起作废。
- 删除只影响群消息，不会改动账本里的系统点和背包。

#### 截断提示（1.1.4）

回复达到输出上限被截断时，最后半条会被丢掉，群里出现一条 ⚠ 提示。这时可以「↻ 重roll」，或者在 群务 →「群聊生成」调高输出上限、调低每条字数。

注意：走「酒馆主 API」时，酒馆不返回结束原因，插件识别不到截断，直接调高输出上限就行。

### 8.2 群员

- **发布招募令**：每次 100 点（失败退回），入群费按实力档。方式有三种：
  - 随机世界：按你的系统点挑实力档；
  - 指定世界；
  - 指定角色：输入名字会自动改成「指定世界」。
  - 填好后点「发布」。
- 「扩建 +5 · 金额」：群人数上限加 5（初始 5 人），当前容量 ×1000 点；第一次 5000 点，后续随容量增加。
- **从世界书召唤（1.1.5）**：招募令下面的卡片。
  1. 选一本世界书（★ 是当前聊天正在用的；「诸天万界最强系统」不在列表里）；
  2. 输入角色名或关键词（留空列出全部），点「查找」；
  3. 在结果里点「召唤」：模型按条目内容整理出群员资料（名称 / 出处 / 实力档 / 性格 / 特产），成为候选人。费用和招募令一样：每次 100 点（失败退回），「邀请入群」时按实力档付入群费；
  4. 入群后群员卡片上有「📖 世界书」标记，鼠标停在上面显示出自哪本书的哪个条目。
  - 插件**只读**世界书，不会改动世界书文件；群员只记下「书名 + 条目编号 + 条目名」。条目被删除后，群员照常在群里，只是不再带条目资料。
  - **群聊 / 私聊**时，会把召唤群员自己的条目（每人约 360 字）和对话里关键词命中的同书条目（最多 3 条）附给模型，总字数有上限（默认 1,600 字）。
  - **群员记忆注入**：正文最近 4 层里出现了这位群员的名字或条目关键词时，发给正文 AI 的聊天群摘要里会多一段「群员记忆」：TA 最近的群聊、和你的私聊、经聊天群给你的东西、好感。这样 TA 在剧情里出场时会记得群里的交流。需要本聊天的「剧情摘要注入」开着；可在 设置 → 功能开关 → 聊天群 关掉。
- 每位群员的按钮：

| 按钮 | 用途 |
|---|---|
| 私聊 | 和这位群员单独聊天。 |
| 拉入羁绊 | 把 TA 加进羁绊页（群员默认不进羁绊）。 |
| 降临 · 按钮金额 | 按实力档支付按钮所示费用后，TA 通过聊天群降临，接下来 3 轮剧情里登场。同一时间只能有一位降临。 |
| 直播 | 让 TA 开一场群直播。 |
| 设管理 | 设为 / 取消管理员。 |
| 禁言 | 禁言 3 轮，再点一次解除。被禁言的群员不发言。 |
| 踢出 | 移出群聊（会确认）。 |

### 8.3 集市

- **群员挂单**：「看看今天的货」，每天刷新。品阶按群规：不高于商城等级，也不高于群员实力。
- **我的挂单**：选背包物品，填售价（空着就按估值），点「挂单」。售价高于估值 30% 时，群员会嫌贵。

### 8.4 群务

- **群资料**：群名、公告（置顶，也会告诉群员）、群规（每行一条，每次群聊请求都会带上），改完点「保存」。
- **规则底线**：不能关闭，比如禁忌品不得在群内流通。
- **与剧情联动**：
  - 「群聊摘要注入剧情」：把群员和最近群聊写进主聊天的提示；
  - 自动闲聊间隔：每 1 / 2 / 3 / 4 / 5 / 6 / 8 / 10 轮。
- **群聊生成（1.1.4）**：

| 设置 | 选项 | 默认 |
|---|---|---|
| 每次最少几人发言 | 1–6、8、10 人 | 1 |
| 每次最多几人发言 | 1–6、8、10 人 | 6 |
| 每条消息字数上限 | 120 / 200 / 300 / 400 / 600 / 800 字 | 300 |
| 带给模型的最近消息条数 | 8 / 16 / 30 / 50 条 | 16 |
| 输出上限（max tokens） | 自动 / 1200 / 2000 / 3000 / 4000 / 6000 / 8000 | 自动 |

- 下限大于上限时，另一项会跟着调整。
- 「自动」的计算方式：600 + 最多人数 × (每条字数 + 20)，限制在 1200–6000 之间。
- 输出上限的优先级（从高到低）：
  1. 连接页「分功能 API」里给聊天群单独设的上限；
  2. 这里选的具体数值；
  3. 连接页的默认最大输出；
  4. 自动估算。

## 9. 莉莉丝

### 9.1 工作台

和莉莉丝商量下一步怎么走：

1. 选「这次想做什么」（咨询与规划 / 拟定长期·短期任务 / 复核现有任务进展）。
2. 选「携带多少近期消息」（4 / 6 / 10 / 12 条）。
3. 写下你的问题或打算。
4. 点一个按钮发出请求：「梳理未竟之事」「规划下一步」「让莉莉丝想一想」。也可以先点「先看发送资料」，看看这次会发给 AI 什么。
5. 「莉莉丝的回信」里是建议草稿，可以编辑。建议不会被当成已经发生的剧情或任务。
   - 「暂停自动接续」：下一轮正文不再自动承接这条建议。
   - 「旧方式：放入聊天输入框」。
   - 「往来记录」：查看以前的回信。
- 「查看当前任务 · 原账本只读」「本次发送的资料」：展开查看。

### 9.2 记忆

- **记忆契约**（按聊天保存）：
  - 在当前聊天启用助手与记忆注入；
  - 正文结束后自动整理（每轮最多一次独立请求）；
  - 下一轮正文自动承接记忆与工作台建议（不改旧楼层）；
  - 莉莉丝监管账本与奖励。
  - 「立即核验最新正文（不请求模型）」。
  - 「每轮提示预算 · 字符」。
  - 改完点「保存当前聊天设置」。
- 「整理最新回复」「补读最近 6 条回复」：手动整理记忆。「取消当前请求」。
- **固定提醒**：写一条一直生效的提醒（比如「张三没有被遣散前，始终作为常驻打手随行」），点「保存提醒」。
- 「查询已保存事实」：按人物、任务、物品名搜索。
- 「导出记忆与草稿备份」。
- **1.1.4**：模型写出不合格的记忆键（带「·」「：」、空格、日文、全角，或者同一批重复）时，插件会先自动清洗，不再整批报「记忆键重复或不安全」。

### 9.3 规则（诸天规则藏书）

- **额外世界背景**：
  - 「读取书目」列出酒馆里的世界书；
  - 选一本，点「读取这本书」，作为莉莉丝的额外背景；
  - 「仅用内置规则」：不用额外背景。
- **查阅完整条目**：按关键词（任务、打手、盲盒、时光投放……）查原版规则全文。

### 9.4 私聊、触摸与立绘

- **私聊**：点悬浮莉莉丝或头像打开莉莉丝窗口，就能和她单独聊天（用「莉莉丝」的 API 配置）。私聊内容存在本聊天里。
- **触摸互动**（设置里可关）：
  - 在立绘的部位上点 / 来回抚摸：会有逐级台词和表情；
  - 按住不动 0.65 秒：长按反应；
  - 触屏时视线会跟随手指；
  - 手机上会有震动反馈。
- **立绘模式**（设置 → 系统助手；1.1.4 及以前叫「莉莉丝」分组）：
  - 原版分层动画（伪 Live2D）；
  - 原版 + 表情差分（随语气切换）；
  - 真 Live2D（需要自备 Cubism 模型，在「立绘 / Live2D 设置 ›」里绑定）。
- **换人设以后（1.1.5）**：悬浮莉莉丝、分层立绘、表情差分、触摸互动只属于莉莉丝；其他人设用圆形头像（终端左上角和唤醒按钮），立绘位置显示人设头像并轻微呼吸发光。私聊照常可用，窗口标题和对方名字换成人设名。
- **界面角色**：进入系统页时说一句；对选中的任务 / 物品 / 功法和结算成败作出反应；镜头在系统页是半身，在工作台是全身，在私聊是面部特写（这些都可以分别关掉）。

## 10. 终端页

### 10.1 连接（AI 接口）

- **接口预设**（顶部下拉框）：选一个就载入；「删除」删掉当前预设。
- 两种方式：
  - **单独的 API（推荐）**：填 OpenAI 兼容接口地址（一般以 /v1 结尾）、API 密钥、模型（可以点「拉取模型」或手填）；
  - **直接用酒馆正在用的模型**：不用填地址；但每次请求会占用主聊天，主聊天生成时要等它。
- 「测试连接」「保存」。
- 「保存为预设」：要先填预设名称（例如「公益站 A」）。
- **分功能 API**（可选）：每个功能可以单独选「跟随默认 / 酒馆当前主 API / 某个预设」，或点「用上面填写的」。功能包括：
  - 万界商城 AI 进货、盲盒抽取、许愿池、诸天打手、背包整理 / 熔炼、能力档评估、品阶鉴定；
  - 聊天群（群聊、私聊群员、招募令、降临、挂单）；
  - 数据块补记、莉莉丝私聊、记忆整理、工作台。
- **高级设置**：
  - 默认 / 预设最大输出（tokens，含思考；留空由各功能决定，可以分功能覆盖）；
  - 哪些功能用这套接口（状态栏 AI 功能 / 莉莉丝）。
- 下半部分「与莉莉丝建立连接」是原版莉莉丝的接口表单：地址、Key、模型、最大输出长度，以及「保存连接配置」「测试连接」「取消连接请求」。
- 密钥只存在你自己的酒馆和浏览器里，不会写进聊天记录，也不会被导出。

### 10.2 状态

- 酒馆环境检测、权限边界。
- 「下一轮有效记忆提示」：下一轮会注入的记忆。
- 「工作台请求记录」。

### 10.3 说明书（1.1.4）

就是这份文档。顶部搜索框可以按功能或按钮名搜索（多个词用空格分开）；目录可以折叠，点章节名就会跳过去。

### 10.4 设置

见第 11 章。设置页顶部有搜索框（例如搜「悬浮」「世界书」「超时」）。

### 10.5 功能开关（1.1.5）

设置 → 上手 →「功能开关 ›」。见第 19 章。

### 10.6 系统助手人设（1.1.5）

## 12. 聊天楼层里的东西

### 12.1 数据块 `<ZhuTianPanel>`

AI 每轮在回复末尾写一个 `<ZhuTianPanel>…</ZhuTianPanel>` 数据块（字段: 值）。插件读取后记账，楼层里只留一个小标签「✧ 系统已记录 系统点 … 任务 … 查看 ›」。点小标签打开终端并定位到这一层。

- 每层只记一次账。重新生成（swipe）时，先回滚到这一层之前的账本，再记新回复，资源不会叠加。
- 旧楼层的数据块不发给 AI（可关）。

### 12.2 莉莉丝语音框

正文里「莉莉丝：“……”」会显示成带头像的语音卡片（可关）。**1.1.4**：思维链里的台词不再被做成卡片。

### 12.3 思维链保护（1.1.4）

如果你用的预设会输出 `<think>` / `<thinking>` 等思维链：

- 数据块守卫修复时，数据块**外面**的思维链原样保留，标签不会被补、被挪、被删。
- 思维链里写的数据块**草稿**会被停用：标签改成全角 `＜ZhuTianPanel＞`，阅读不受影响，但不会再被当成正式数据块。以前这种草稿会和正式数据块的结束标签配对，把 `</think>`、正文和正式数据块一起吞掉，这是 1.1.3 里能「卡掉」思维链标签的真实路径。
- 数据块只写在思维链里时，会被搬到正文后面，思维链本身不变。
- 回复被截断、思维链没有闭合时：这一层不修复，也不补记。
- 旧楼层（1.1.4 以前保存的）显示、记账和提示过滤时，也会跳过思维链里的草稿。
- 非诸天聊天：插件不处理（只处理诸天存档或带数据块的楼层）。

<a id="chapter-13"></a>

## 13. 账本安全

### 13.1 加锁写入

本插件账本写入采用「加锁 → 写入 → 从服务器读回核对」的保护流程；原版桥接与原生结算的处理细节不同，未逐项验收的支付操作仍以第17章边界为准。同一时间只有一个操作在写；支持相应锁机制时协调多个标签页；不同浏览器或不支持的宿主不能据此保证绝无冲突。

### 13.2 冻结与「核对并解冻账本」（1.1.4）

- 写入后读回的内容和写入的不一致时，账本会**冻结**，防止重复提交。提示是「此前原生结算写入状态不明，已冻结此聊天的所有账本写入」。
- 1.1.4 修复了误冻结：以前其他卡 / 脚本的变量变化、酒馆迟到的保存，都会被当成写入失败。现在只比对这次写入改过的项；不一致时，桥接写入会尝试重存再读；原生账本流程重读确认，不把所有路径都当成重复保存。
- 真的冻结了：设置 → 诊断与维护 →「**核对并解冻账本**」。
  - 服务器存档和页面**一致**：直接解冻，不用刷新。如果刚才那笔操作没生效，重新做一次就行。
  - **不一致**：会列出不同的项，并询问是否重载页面。重载后以服务器存档为准，冻结自动解除。

### 13.3 备份与回滚

- 原生账本写入流程保留最近最多 5 份自动备份：设置 →「旧存档迁移 / 账本回滚 ›」。
- 导出 / 导入存档：账本、记忆、设置（不含密钥）。

## 14. 常见问题

**提示「此前原生结算写入状态不明…已冻结」？**
设置 → 诊断与维护 →「核对并解冻账本」。见 13.2。

**提示「记忆整理失败：记忆键重复或不安全」？**
1.1.4 已经修复，记忆键会先自动清洗。更新后还出现，请用「复制诊断信息」反馈。

**思维链标签不见了 / 被「卡掉」？**
1. 先用 设置 → 诊断与维护 →「检查最新楼层：插件动过吗？」。
2. 如果报告说正文**没有被改写**、楼层**不是插件渲染的**，那多半是预设、其他扩展或正则造成的，逐个停用后再试。
3. 如果是诸天存档，还有两点可以检查：
   - 「格式提醒插入深度」保持 1；
   - 世界书「诸天万界最强系统」里有 3 条常驻条目插在深度 0（04 状态栏数据块与实时数据、05 状态栏规则补充、34 统一实力标尺与报价口径，合计约 3,700 字），会排在最后一条消息之后。如果你的预设靠最后一条消息或预填充来开启思维链，可以在世界书里把这 3 条的深度改成 1 或 2，再试。

**聊天群回复被截断？**
群务 →「群聊生成」调高输出上限，或者调低每条字数 / 最多发言人数。截断的一轮可以「↻ 重roll」。

**群消息想删 / 想重来？**
「🗑 管理」逐条删除，「↻ 重roll」重来最近一轮。已经领取的红包 / 赠礼不能撤。

**想把莉莉丝换成别的系统 / 不想要魅魔人设？**
设置 →「系统助手人设」选「系统光球（编号）」或「自定义」，保存即生效；随时可以「换回莉莉丝」。世界书文件不会被改。

**有些功能用不上、想关掉？**
设置 →「功能开关」。关掉的功能数据都保留；不用的页面可以从导航里拿掉。

**聊天群能不能拉我世界书里的角色？**
能：聊天群 → 群员 →「从世界书召唤」（见 8.2）。

**抽卡太慢？**
用「经典折叠」模式：一次请求生成全部未折叠物品。

**AI 回答没有数据块？**
打开「缺少数据块时自动补记」，或手动点「补记最新一层数据块」。

**手机上终端太小 / 太大？**
设置 →「手机上的终端与私聊窗口」，或者用标题栏的「全屏 / 浮窗」。

## 20. 阅读方法和操作前的共同规则

前面的第 1 至 19 章是功能速查，后面的章节按实际操作补齐按钮、输入项、结果和失败处理。同一按钮在不同页面出现时，按所在页面分别解释。例如群聊的「发送」和助手私聊的「↑」用的接口、保存位置、是否影响正文都不相同。

**本说明书对应 1.1.5-r1。** 扩展列表显示 1.1.5，诊断里的修订显示 1.1.5-r1。此版包含 1.1.4、1.1.5 和 r1 修订。后续版本按钮可能增减；旧截图或旧教程不一定与这里一致。

### 20.1 先分清三种动作

| 动作 | 点下去的结果 | 典型按钮 |
|---|---|---|
| 查看和切换 | 打开资料、换页、展开说明，不会因为查看而发奖 | 详情、上一页、下一页、在关系图查看、返回设置 |
| 请求 AI | 把本次需要的资料交给配置的模型，等待回答；服务商可能收 API 调用费 | 询价、提取候选、AI 鉴定、让助手想一想、群聊发送 |
| 改动账本 | 修改系统点、物品、任务、关系、开关或存档，按该动作规则保存 | 购买、保留、分解、回收、领取、邀请入群、写入账本、确认导入 |

系统点是游戏里的数字，API 调用费是模型服务商收费。生成失败“不扣系统点”不代表服务商一定不收费。开启自动记忆、自动闲聊、缺失补记，可能在一轮正文之外增加请求。

### 20.2 保存方式

普通「设置」页和「功能开关」页的下拉框、开关改完就交给酒馆保存，没有额外的统一保存按钮。人设、商品定制、群资料、记忆契约、固定提醒、接口配置、管理员面板则各有自己的保存按钮；只填写表单还不算保存。

换聊天后，系统点、背包、聊天群、人物关系和助手记忆跟着当前聊天切换。人设、配色、悬浮窗大小、商品定制、接口预设等属于扩展设置或全局配置，会影响使用这份配置的其他聊天。

### 20.3 灰色按钮和确认窗口

灰色通常表示正在请求、缺少条件、空列表、当天已经签到、群容量到上限或功能被关闭。先看按钮旁的文字、提示气泡和页面底部状态，不要连续点击。确认窗口的「取消」会放弃这次尚未执行的动作；已经成功扣款、入库或删除的动作，不会因为关闭窗口自动撤销。

遇到“写入状态不明”“已冻结”，先核对存档，别把反复点击当成重试。确认当前账本后再决定是否重做。不同功能保留的数据量不同：群消息最多 150 条、每位群员私聊最多 30 条、群聊重roll记录最多 5 轮，本地操作日志最多 100 条；它们不是永久保存全部历史的聊天档案。

## 22. 总览 任务 羁绊和修行的逐按钮说明

### 22.1 总览

点「总览」只查看当前账本。系统点、当前货币、持有金额、子系统数量、子嗣数量、专属资源等数值没有一键领取的含义。

| 控件 | 如何使用 | 结果与范围 |
|---|---|---|
| 当前货币卡片上的神豪切换 | 点击卡片中的开关 | 切换原版神豪显示与规则关联；不能当成无限系统点按钮，商城仍检查系统点 |
| AI 可见数据（诸天系统.实时数据） | 点击标题展开或收起 | 查看供正文规则使用的账本摘要，不是在这里编辑全部账本 |

### 22.2 任务

任务列表按页显示，每页 8 项。「进行中 / 待接取」用于日常继续任务；「长期任务」「短期任务」按类型筛选；「已归档」看已经结束的任务；「全部任务」包含各状态。

| 按钮或控件 | 做什么 | 不会做什么 |
|---|---|---|
| 任务筛选下拉框 | 只改变当前展示范围 | 不删除被隐藏的任务 |

| 查看事件线 › | 打开任务、结算与穿越的关联记录 | 不重发奖励 |

任务进度与结算主要由正文的数据块记录。群聊求助产生的是「待接取」任务；助手工作台给出的任务方案是建议草稿。看到建议不等于账本里已经发布并完成了任务。

| 全部 | 查看各世界的人物 | 可能包含同名不同世界的人物 |
| 恋人·攻略 | 只看相应关系类别 | 类别以已保存关系为准 |
| 打手 | 看打手人物 | 打手的忠诚与普通羁绊的好感不同 |

### 22.4 功法和修行

| 按钮或控件 | 做什么 | 需要留意 |
|---|---|---|
| 主修 | 把这门功法设为当前主修 | 其他功法仍在库中；不是删除旧主修 |
| 功法旁的 ✕ | 确认后移出功法库，同时删除对应熟练度记录 | 删除当前主修会清空主修显示；先备份 |

## 23. 商城 盲盒 许愿 背包和回收的完整操作

### 23.1 商城顶部分区

「万界盲盒」「待处理奖励」「万能许愿」「商城库存」「物品回收」五个按钮用于滚动定位到对应区块，不是五笔交易，也不扣系统点。切换分区后，列表数据还是当前聊天的数据。

### 23.2 抽卡按钮和模式

| 按钮 | 实际含义 | 成功后的去向 |
|---|---|---|
| 单抽 · 1万 | 抽 1 次，需 10,000 系统点 | 未处理奖励进入待处理物品列表 |
| 十连 · 10万 | 抽 10 次，需 100,000 系统点 | 同上 |
| 五十连 · 50万 | 抽 50 次，需 500,000 系统点 | 经典模式中的凡品会合并显示 |
| 自定义抽数 | 读取旁边数字，一次按 1–200 抽处理，每抽 1 万点 | 输入过大不会变成无限抽；按当前上限处理 |
| 经典折叠 | 整次生成完成后一起扣费结算 | ≥50 抽合并凡品，≥100 抽再合并灵品 |
| 十抽一结算 | 分成最多十抽的小批次，逐批生成、扣费并保存 | 后面失败时，已经成功的前面批次仍保留 |
| 收下奖励 | 关闭抽卡结果展示 | 仍应检查待处理奖励，保留或分解；关闭弹窗不代替「保留」 |

概率是凡品 60%、灵品 38%、仙品 1.9%、神品 0.1%；仙品 100 抽保底，神品 1000 抽保底；禁忌不在盲盒奖池。品阶、保底和数量由插件计算，模型负责给未折叠奖励生成具体内容。

折叠不会白白吃掉奖励。例如「凡品杂物 ×30」仍代表 30 份，保留时按数量入库，分解时按数量计价。它不生成 30 个独立物品名，适合希望减少等待的人。经典模式一般一次模型请求即可，但回答截断、不合格时会重试，不能保证永远只请求一次。

余额不足会在开始生成前拒绝。经典模式在成功写账本前失败不扣该次系统点；十抽一结算是按完成批次收费。请求过程中不要切聊天、改保底或重复提交。

### 23.3 待处理奖励

| 按钮 | 对哪个范围生效 | 保存结果 |
|---|---|---|
| 保留 | 当前这一行奖励，包括该行数量 | 从待处理移走，加入背包；不再额外收费 |
| 分解 +金额 | 当前这一行奖励，包括该行数量 | 奖励被消耗，系统点增加所示金额 |
| 分解全部 +金额 | 当前按钮所属品阶的所有待处理奖励 | 不是所有品阶；点之前看品阶和预计回收金额 |
| 一键全部保留进背包 | 当前全部待处理奖励 | 全部进入背包，待处理清空 |
| 上一页 / 下一页 | 只翻待处理列表页 | 不处理、不领取物品 |

保留和分解互相排斥，一份奖励不能先保留又分解一次。列表在点击后已经变化时，插件会停止或要求重新点击，避免对错物品操作。批量操作按待处理列表执行，不是只处理你屏幕上看得到的几行。

### 23.4 万能许愿

「输入愿望」写你想得到的结果；点「询价」会请求模型，给出品阶、报价和评估理由，这时还没支付系统点。看清报价后点「支付并加入待结算」，才扣报价中的系统点，并加入本次操作的剧情记录。界面提示愿望达成，不代表正文已经替你写好，仍需通过操作摘要衔接剧情。

改了愿望后应重新询价，不要把上一份报价当成新愿望价格。余额改变时会重新检查。被判定不能用许愿实现、价格为 0 的内容不提供正常支付；按提示改用对应模块。专属资源计数、让别人爱上你、复活与复制能力等有各自规则，不应靠许愿绕过。

### 23.5 库存 购买和商品详情

| 按钮 | 作用与费用 | 结果 |
|---|---|---|
| 一键进货 · 500 系统点 | 请求模型生成并校验 8 件新库存，成功时扣 500 点 | 替换本次库存，不是免费发 8 件物品到背包 |
| 商品定制 / 近期避重 | 打开商品定制页 | 不进货、不扣系统点 |
| 详情 | 打开该件商品的完整描述 | 不购买 |
| 购买 | 支付该件库存价，按规则应用普通商品名望折扣 | 当前库存行标为已购，物品入背包 |
| 已入手 | 表示这份库存已卖出 | 不能再次领取这份；以后进货仍可出现同款 |
| 关闭 | 关闭商品详情 | 不撤销已经完成的购买 |

普通商品没有由商城等级、当前世界或修为另加的购买与使用门槛；聊天群、神通、种田等模块自己的限制仍按各模块规则走。普通商品名望每 1000 减 1%，最高减 30%。禁忌购买不享这项折扣。

### 23.6 神品与禁忌

| 项目 | 神品 | 禁忌 |
|---|---|---|
| 规则定位 | 行星级、星系级以上等高阶效果 | 概念、全能级效果 |
| 商城价格 | 1 亿系统点起 | 至少 100 亿系统点 |
| 获得渠道 | 商城、盲盒神品概率和保底等 | 符合条件后的商城进货机会，不进盲盒池 |
| 进货条件 | 普通库存规则 | 当前系统点至少 100 亿且因果筹码至少 1，才有 2%机会 |
| 购买代价 | 库存价格与普通折扣规则 | 库存价格加 1 因果筹码，购买前确认 |
| 获得后限制 | 按物品本身描述 | 无额外的使用门槛、寿命惩罚或反噬 |

这是品阶定位，不是固定的“禁忌等于神品多少倍”。物品实际效果以该件描述为准；消耗品仍按其本来的数量和一次性用途处理。

### 23.7 背包和物品回收

| 控件 | 实际动作 | 重要区别 |
|---|---|---|
| 分类与翻页 | 按分类查看或翻页 | 不改变物品分类、数量 |
| 详情 | 看完整效果、来源等 | 不请求 AI，不使用物品 |
| 使用 | 把使用要求放进主输入框；分类含“消耗”的物品立即扣 1 件，其他保留 | 消耗品不是等正文成功后才扣，发送前核对 |
| AI 背包整理（重新分类 + 补全功能简介） | 发出整理请求，补分类和简介 | 不应当成新增奖励；整理前后核对数量与效果 |
| 回收数量输入框 | 选这次回收几件 | 按实际库存限制，默认 1 件 |
| 回收 | 消耗所选数量并得到系统点 | 普通回收价为单件计价的十分之一、向下取整且至少 1；不是原价退款 |
| 品阶鉴定 › | 跳到剧情品阶鉴定 | 升品阶不会按新版品阶凭空抬高已记录回收价 |

同名物品不一定是同一件。同名、同品级但来源、价格、分类或效果不同，会分行保留；看清行的具体信息再使用或回收。

## 24. 商品定制 剧情收纳 品阶鉴定和操作摘要

### 24.1 商品定制表单

商店进货和盲盒奖励各有一份配置，保存一份不代表另一份也改了。修改定制只影响之后生成的内容，不重写已经买到的物品，也不改变盲盒概率。

| 输入项或按钮 | 怎样填写 | 生效方式 |
|---|---|---|
| 来源 诸天混合 | 希望跨多作品、多世界生成时选 | 组合选定题材 |
| 来源 当前世界 | 希望贴近现在剧情时选 | 读取账本里的当前世界 |
| 来源 指定世界/作品 | 希望来源固定时选 | 旁边必须填作品或世界原名 |
| 指定作品/世界（原名） | 如实填原作名称，不只写模糊简称 | 不是让插件自动联网查原作 |
| 混合题材 | 至少选一种题材 | 可以多选，影响内容组合 |
| 商品类别 | 至少选一种类别 | 消耗品、武器、装备、服装、素材、其他 |
| 用途 | 至少选一种用途 | 探索、生活、治疗、战斗、建造、情报 |
| 排除项（逗号分隔） | 写不想出现的物品或题材 | 用于后续筛选，不删除旧背包 |
| 允许原创 | 接受原创内容时勾选 | 模型声明“原作”仍不等于已查证原作 |
| 近期避重（含相似效果） | 希望少出现换皮重复商品时选 | 根据近期商品记录筛选 |
| 允许常用消耗品重复 | 接受常用补给再次出现时选 | 不等于取消所有数据校验 |
| 保存商店配置 | 检查来源、题材、类别、用途后点击 | 保存商店的定制 |
| 保存盲盒配置 | 同上 | 保存盲盒的定制 |

### 24.2 剧情收纳的输入项

位置「交易 → 剧情收纳」。这是把正文已经获得的东西补登记，不是凭空生成道具，不收系统点。

| 输入项 | 作用 | 例子或边界 |
|---|---|---|
| 起始楼层 / 结束楼层 | 指定给模型读取的正文范围 | 用酒馆的楼层编号，从 0 开始；先核对获得发生在哪一层 |
| 来源世界 | 保存物品或功法来自哪个世界 | 不是只根据当前显示世界猜来源 |
| 附带当前角色卡描述 | 给鉴定模型补背景，最多 6000 字 | 资料会发送给你配置的鉴定接口 |
| 世界书选择 | 可附带一本世界书作为参考，也可不附带 | 这是给模型资料，不会把世界书全改写 |
| 该世界品阶映射 | 用 JSON 写原世界等级与系统等级的对应 | 不知道可以保留默认；格式不对先改格式，不覆盖角色卡 |
| 提取候选 | 请求模型找可能获得的物品或功法 | 提取完成仍未正式入库 |

### 24.3 候选项和确认按钮

每张候选卡显示名称、物品或功法类别、证据楼层、原文、效果、原世界品阶、系统建议与理由。逐项核对是不是**宿主实际获得**，不能把敌人的装备或旁人修炼的功法直接收成自己的。

| 控件或按钮 | 作用 | 保存结果 |
|---|---|---|
| 确认归属并收纳 复选框 | 选中本次要处理的候选 | 没勾的候选不会因为列表出现而入库 |
| 系统建议 品阶下拉框 | 人工确认系统品阶或保留待鉴定 | 原世界品阶仍单独记录 |
| 数量 | 修改这次实际获得数量，界面范围 1–100000 | 不要为了重复领取而虚增数量 |
| 背包已有同名物品，但这是明确新获得的另一份 | 只在物品确实是新获得的一份时勾选 | 不能把同一证据当第二次获得 |
| 确认选中项入库 / 暂存待鉴定 | 提交选中的候选 | 品阶明确的正式收纳，不明确的放待鉴定库 |
| 待鉴定记录的品阶下拉框 | 给暂存记录选择明确品阶 | 先看证据再选择 |
| 确认品阶并入库 | 把该条暂存转成正式背包或功法记录 | 已正式收纳不应重复登记 |

「已收纳」是来源记录，当前剩多少件要以背包为准：用掉、卖掉、分解后，来源证据不代表物品仍在。

### 24.4 品阶鉴定

「AI 鉴定」会把待鉴定对象与背景交给配置的鉴定模型；鉴定修改的是品阶及相关功法上限等记录，不重新生成一份。只有符合剧情、角色卡、旧存档来源条件的对象会进入这类鉴定列表；不把系统奖励随意升成禁忌。

「手动修正…」下拉框可以不请求模型直接选更高品阶。此功能只升不降，最高神品；「已是最高」表示没有进一步提升选项。「‹ 返回」回到进入前的页面。人工升品阶是你对已有资料的修正，不能当成模型已经证实了原作设定。

### 24.5 操作日志与操作摘要不是同一个界面

左侧「操作日志」显示最近 100 条本地操作，便于核对交易，不自动发给模型，也没有交易撤销按钮。商城原版区域里的本次操作记录，另外提供选择后发送的摘要工具。

| 按钮 | 实际选择或动作 | 影响范围 |
|---|---|---|
| 全选 | 勾选当前展示记录 | 不重新执行这些操作 |
| 全不选 | 去掉所有展示记录的勾选 | 不删除账本凭据 |
| 物品 | 只选择物品相关展示记录 | 改勾选范围 |
| 分解/回收 | 只选择这类展示记录 | 默认这类记录不一定被勾选 |
| 剧情 | 只选择其他剧情相关记录 | 改勾选范围 |
| 清空展示 | 确认后清空当前操作展示 | 不退款、不删背包、不清凭据、不撤交易 |
| 预览选中的剧情摘要 | 打开将要写给正文的摘要 | 没有选中可发记录时会提示 |
| 写入主输入框 | 把预览内容放进主聊天输入框 | 仍由你发送；预览文字可先修改 |
| 写入聊天输入框 · 检查后发送 | 旧界面可能出现的摘要入口文字 | 当前插件增强后通常显示为预览按钮，按实际文字操作 |

摘要会告诉正文 AI：操作已经完成，不要再次扣点、发奖或入库。摘要的用途是让剧情承认已发生的操作；发给 AI 后再被叙述一遍，不代表可以第二次领奖。

## 25. 外挂工坊和自拟外挂的逐按钮说明

### 25.1 分区按钮

「无限口袋」「诸天打手」「洞察之眼」「分身派遣」「随身洞天」「万物熔炉」「操作记录」用于滚动定位。它们只是导航。带「支付」「种下」「开炉」「取出」的按钮才会执行对应动作。

### 25.2 无限口袋

先从背包下拉框选物品，再点「存入」。口袋一次保存一种物品，新存入会替换旧口袋模板；当前处理是记录物品模板，不是每次取出都从背包旧数量中扣同样数量。

「取出 ×N 个」读取数量，范围 1–9999，把对应数量加进背包。「清空」清掉口袋保存的模板，不回收已经取出的物品，也不会清空整个背包。口袋空时不能取出；被原版外挂开关关掉时，对应功能不可正常发动。

### 25.3 诸天打手

「角色名」填要召唤的人物；「出处」可帮助模型区分同名人物；点「召唤」会请求模型生成打手资料并登记打手卡。这不是聊天群的“发布招募令”，当前这个按钮没有实现那套“100 点招募＋分档邀请入群”的扣款流程，不能把两者费用混为一谈。

打手卡「详情」查看战力、忠诚和特长；「遣散」移除打手并尝试把合理退场的要求写入主输入框，或加入操作记录。它不是暂时隐藏人物；你需要让正文承接退场，也不应期待自动返还招募花费。分页按钮只翻打手列表。

### 25.4 洞察之眼

「洞察对象」输入具体人物；「对象实力档」选这位人物的档，不是宿主档；「情报深度」选表层档案、隐秘情报或底牌弱点。表层档案查看身份与状态；隐秘情报涉及秘密与关系；底牌弱点更深入、报价也更高。看清当前报价后点「支付并洞察」。成功后系统记下花费和洞察操作，具体情报需要剧情衔接，不能把只点按钮当成正文已经补齐全部信息。

### 25.5 分身派遣

「派往世界」输入分身要去的世界；「任务」选择打工赚点、代为修炼或探宝寻缘；「时长」选 3 / 5 / 10 轮。这里的“轮”按剧情进展计，不是现实计时器。

| 按钮 | 结果 | 代价与限制 |
|---|---|---|
| 支付并派出 | 扣界面报价，建立派遣记录 | 看可用分身容量、目标世界与实力档 |
| 提前召回 | 确认后结束未完成派遣 | 明确是一无所获，不会给正常完成奖励 |
| 领取 | 派遣完成后结算收获并移除该派遣 | 打工加点、修炼加熟练度、探宝入背包；不能重复领 |

代为修炼没有主修功法时，当前原版结算会转成打工收获。探宝的“待鉴定”描述要在后续剧情或鉴定流程里确认，别把未知名称当成已查明的原作宝物。

### 25.6 随身洞天

先选灵种品阶，界面显示成本与成熟轮数：凡品5点/2轮、灵品500点/4轮、仙品50万点/6轮、神品500万点/10轮。「种下灵种」扣相应系统点并占一块空田；田满时先收获或扩建。当前原版种田规则中神品灵种要求商城Lv4，与普通商城商品取消等级门槛是两件事。

成熟后出现「收获」，点后物品加入背包，该田变空。「扩建灵田」每次消耗 5 岁月沉淀，增加一块田，上限按页面显示；不是消耗 5000 系统点。专属资源不足或到上限时不能扩建。

### 25.7 万物熔炉

从两个背包物品下拉框选材料，检查数量、品阶和报价，再点「开炉熔炼」。它会消耗材料并按规则产生新物品，存在失败成炉渣或升品阶的随机分支；不是免费让 AI 改个名字。配置了接口时还可能请求模型补新物品名称和效果。

同一行材料能否同时选两份，以数量检查为准；至少要够本次消耗。完成后核对背包与记录。该支付类功能尚未完成逐按钮真实模型验收，首次尝试前保留存档。

### 25.8 外挂管理的三个范围

| 控件或按钮 | 作用范围 | 操作结果 |
|---|---|---|
| ＋ 自拟外挂 / 外挂管理 › | 打开管理页 | 不立即发动 |
| ‹ 返回外挂工坊 | 返回外挂页 | 不丢弃已经保存的外挂 |
| 强力模块 开关 | 修改安装的诸天世界书对应条目的启停，影响共用这本书的聊天 | 条目不存在时无法切换 |
| 一键平衡：关闭… | 一次关掉当前列出的强力模块 | 以按钮列出的模块为准，不是恢复所有游戏数字 |
| 原版外挂 开关 | 当前聊天 | 关对应外挂的使用与提示；不删除数据 |
| 自拟外挂 开关 | 当前聊天 | 启用或停用这份库中的外挂 |
| 发动 ·代价 | 当前聊天当前外挂 | 依代价、次数、冷却检查后扣费并记录；被动型不提供同样的主动按钮 |
| 编辑 | 本机外挂库 | 将资料载入编辑表单 |
| 删除 | 外挂库中的这一项 | 确认后删除，先导出想保留的内容 |
| 导出 .json | 本机外挂库 | 下载可分享的外挂配置 |
| 导入 .json | 本机外挂库 | 读取配置，按现有导入校验处理；不导入别人的整份聊天账本 |

强力模块开关会写世界书文件；它和 1.1.5 人设、群员资料的“生成时临时读取或替换”不是同一种操作。

### 25.9 自拟外挂的所有字段

「名称」最多 24 字；「品阶」凡品到禁忌；「类型」选被动、主动或每日次数；「每日次数」每日次数型用，范围 1–99；「代价」选无、系统点或专属资源；选专属资源后指定「资源种类」；「每次消耗数量」填写单次代价；「冷却回合」主动型用，范围 0–999；「规则说明」最多 600 字，写效果、限制和副作用；「注入提示词」决定是否把规则交给正文 AI。

新建时点「加入外挂库」，编辑时点「保存修改」才保存。「取消编辑」退出当前编辑。写入库后，还要在当前聊天启用。主动发动记录说明已执行扣费与触发，正文如何表现仍需要 AI 按规则回应，不等于加载了一段可以任意执行的程序。

## 26. 神通 实力档和付费按钮的使用说明

### 26.1 实力设置

实力档分 1 凡人顶尖、2 武道宗师、3 超凡、4 城市级、5 国家/大陆级、6 行星级、7 星系级以上、8 概念/全能。宿主档、目标档、世界上限是不同变量，不能只设其中一个就认为所有报价都相同。

「这两个档位有什么用？」展开规则说明，不收费。「AI 评估实力档」先填写角色、出处和需要评估的能力，再请求模型给档位与理由，辅助选择目标档；它不是自动购买能力的按钮。「实力设置」「图鉴复刻」「状态改写」「言灵改字」「神通记录」五个分区按钮只跳位置。

### 26.2 图鉴复刻

填写角色名、出处、单项能力或全套能力，选择评估档位，检查世界上限、锁定提示和价格。「支付并复刻」成功后扣点，并把能力收录进功法库，按复刻规则起步熟练度。超出世界上限可能有封印与后续解封规则，不可拿普通商城的“无世界限制”覆盖神通模块规则。

### 26.3 状态改写

「目标」填自己或具体人物；「改写类型」选要改变的伤病、诅咒、死亡或减益类型；「改成什么状态（可选）」可明确结果，不填用该类型默认结果；「目标实力档」选目标档；「对方不情愿」勾选敌意情况，会改变报价与抵抗判定；「血脉结晶减价」在复活类按每颗减10%的规则使用；「因果筹码抵实力差」按每枚抵1档的规则使用。输入资源数量是选择本次消耗，不是增加你的资源。

看清所选状态、目标实力与是否敌意对应的报价、成功率、系统点和专属资源要求。「支付并改写」执行后记录成功或失败。对方不情愿的分支不是 100%成功；失败按该分支规则只收部分点数，不能把所有资源都理解为无条件全退。正文中的解释通过操作摘要继续。

### 26.4 言灵改字

「原文（从剧情里复制）」填要改变的句子；「改为」填目标句子；「改写性质」选无害化、小反转或结果反转；「说话 / 出手者实力档」指原句对应行动者，不要误填宿主档；「因果筹码抵实力差」填本次愿意付出的筹码。检查改动字数、成功率和报价后点「支付并改字」。每轮最多 3 次，达到上限要等下一轮；强敌可能抵抗。执行后记录成功或失败与费用。它通过结算记录要求后续剧情承接，不是直接让插件擦掉主聊天里某句话。

### 26.5 记录和跳转

「神通记录」是使用记录；「查看能力树 ›」把功法、神通与外挂汇总展示。查看记录、查看能力树不会再次扣费，也不会再次发动能力。神通支付类按钮属于尚未逐项真实操作验收的范围，说明书解释当前代码规则，不把说明当成真模型已验证的保证。

## 28. 聊天群 聊天红包和消息管理的全部按钮

### 28.1 四个子页和输入框

「聊天」「群员」「集市」「群务」只切换聊天群内部页面。群聊天框最长 300 字；Enter 发送，Shift+Enter 换行；输入法还在确认候选字时不应提交。没有群员时先去招募。出现“正在输入”时等当前请求结束，r1 已把读取世界书期间也算忙碌，避免连点开出两轮。

「发送」通常发出一轮群聊请求，群员回答受群务的人数、字数和上下文设置影响。它不把文字发送给真实用户，群员是模型扮演的角色。群消息与酒馆正文是两套记录，正文能否得知群聊由摘要注入设置决定。

「系统点」和「物品」单选决定发哪种。系统点填总额与分成的个数，个数输入 1–30；物品从背包选一件并填数量。祝福语可选，最多 40 字。点「塞进红包」才从账本扣点或取物并发出红包；点「取消」收起尚未提交的表单。

禁忌物品在群内不得流通，背包空时无法选择物品。发红包有每日发出数量限制（当前 10 次），成员红包进入有每日数量限制（当前 6 次）；没有红包按钮不表示可以靠正文要求绕过。自己的红包已经扣账，不能用删消息或重roll追回。

### 28.4 消息里面的按钮

| 按钮 | 点后的结果 | 何时不能使用 |
|---|---|---|
| 抢 | 从群员红包里抢一份系统点或物品，写入当前账本 | 已抢过、无剩余、红包不存在或不符合领取条件 |
| 领取 | 将群员赠礼登记进背包 | 已领取或赠礼已经作废 |
| 顶部待领取物品名 | 与对应赠礼的「领取」相同 | 显示多份待领时逐份确认 |

红包的点数总额受群员实力、商城等级及招募费用等上限约束，不是模型说多少就给多少；物品红包与赠礼最高不超过群规允许品阶，禁忌会被拦住或降级。出现“已按群规降级”时以实际入账品阶为准。

### 28.5 重roll的完整边界

最近一轮可以来自手动群聊，也可以来自自动闲聊。你的原始输入保留；请求失败旧回复保留。成功后替换旧的群员回复，并撤销这轮尚未领取的红包、赠礼和相应生成计数、节奏等可回退状态。并非退掉其他页面的交易。

本轮已经抢红包或领赠礼，不能重roll。1.1.3 及以前保存的消息没有新轮次记录，不能用重roll重做，只能按允许范围删除。删除普通文字不改变背包和点数；删除未领红包或赠礼会先确认作废。

### 28.6 截断和恢复

独立 API 返回“达到输出上限”时，插件丢掉最后半条，并插入警告。调高群务输出上限或减少人数、字数后，再重roll这轮。走酒馆主 API 时拿不到同样的结束原因，可能没有警告；回复明显断句也要检查输出上限。重roll产生的新请求仍可能被模型服务商计费。

### 29.1 发布招募令和候选卡

随机世界按你的系统点选合适实力范围；指定世界填作品或世界；指定角色填人物名。当前选择随机时，往输入框填写文字会切到指定世界；想明确招某个人，直接选择指定角色。改回随机时会清掉输入，避免误以为仍按已填人物招募。

### 29.2 从世界书召唤

1. 打开「群员」页，在「从世界书召唤」选择书目。★表示当前聊天启用的世界书；插件诸天规则书不在召唤列表中。

4. 生成候选后核对名称、世界、实力档、性格和特产，再「邀请入群」支付入群费。候选还没处理、群满或请求中时先处理条件，召唤按钮会不可用。

“已在群里”是状态，不是再次召唤按钮。群员卡的📖标记用于核对来源书与条目。召唤不导出别人资料，也不修改世界书文件；书目读取的是你当前酒馆已有的资料，不自动联网下载新书。

## 30. 聊天群 集市和群务的完整说明

### 30.1 群员摊位

「看看今天的货」生成本日摊位列表；「重新摆摊」会重新生成当前摊位列表。当前摆摊由本地规则按群员特产和品阶生成，不是每次都请求模型。没有群员时按钮不可用。

每行「金额点 买下」从系统点扣对应价格并把这件物品加进背包，附上群员、世界和集市来源；售出行移除，不能重复买同一份。品阶受商城等级和成员实力限制，禁忌不能在群内流通。普通商城库存的名望优惠不可直接套到这里，按当前集市报价支付。

### 30.2 我的挂单

| 控件或按钮 | 动作 | 结果 |
|---|---|---|
| 背包物品下拉框 | 选择要卖的物品 | 页面展示估值和数量 |
| 售价 | 填成交价，留空用估值 | 单位系统点 |
| 挂单 | 从背包取出1件放到挂单列表 | 没有成交前不增加系统点 |
| 吆喝 | 尝试让群员买这一单 | 售价不高于估值130%且群里有人时按本地成交规则处理；嫌贵时挂单仍在 |
| 撤单 | 把未成交挂单的物品退回背包 | 不另外奖励系统点 |

“挂单”和“吆喝”是两步，不是只点挂单就永久自动卖。已成交的单不能再撤回获得第二份。禁忌不允许挂单。

### 30.3 群资料与联动开关

「群名」最多20字；「公告」最多200字，置顶并发给群员；「群规」每行一条，随群聊请求提供。点这一卡片的「保存」才保存这些文本，不是保存所有全局设置。

规则底线如禁忌不流通、红包与赠礼品阶上限不能靠删除群规文字关闭。「群摘要写进提示词」让正文 AI 看见群存在、群员与最近交流；关闭后仍能手动玩群聊。「剧情后自动闲聊」是当前聊天开关；全局自动闲聊总开关关闭时，本聊天开着也不会自动请求。

「闲聊间隔」可选每1、2、3、4、5、6、8、10轮正文回复；数字越小，请求越频繁。只有打开对应自动闲聊开关才按间隔运行，不是只调整间隔就自动启用。

### 30.4 群聊生成五项设置

| 项目 | 可选值 | 怎样调整 |
|---|---|---|
| 每次最少几人发言 | 1、2、3、4、5、6、8、10，默认1 | 希望多人回应时调高；实际仍受可发言群员人数限制 |
| 每次最多几人发言 | 同上，默认6 | 回复太长或太慢先调低 |
| 每条消息字数上限 | 120、200、300、400、600、800，默认300 | 超出的消息文字会裁掉，长段交流调高会增加输出压力 |
| 带给模型的最近消息条数 | 8、16、30、50，默认16 | 越多越连贯，也越占输入长度 |
| 输出上限（max tokens） | 自动、1200、2000、3000、4000、6000、8000 | 截断时调高，先检查分功能接口有没有更小的覆盖值 |

tokens指模型计数用的文本单位，不等于中文字数；思考模型的预算还可能包含推理内容。自动值按人数和每条字数估算，范围1200–6000。设置下限超过上限时，另一项会调整。

自动闲聊通常最多3人；当前实现下限设得更高时也可能超过3人，不把“自动最多3人”当绝对限制。输出优先级是分功能聊天群接口的上限、群务显式上限、默认连接上限、自动估算。改群务仍没效果时，去连接页核对第一项。

## 31. 系统助手 工作台 记忆 规则和私聊的全部控件

这里的“助手”默认叫莉莉丝，换人设后名字与按钮台词可能替换。开助手窗口不等于每次都请求AI；点发送、整理、规划等请求按钮才会调用模型。

### 31.1 工作台输入项和请求按钮

| 控件或按钮 | 用途 | 点后结果 |
|---|---|---|
| 这次想做什么 | 选咨询与规划、拟定任务或复核任务 | 决定本次分析方向 |
| 携带多少近期消息 | 4、6、10、12条 | 为请求提供相应近期剧情，越多输入越长 |
| 你的问题或打算 | 写具体目标和限制 | 可与当前任务结合，不自动写进正文 |
| 梳理未竟之事 | 用预置问题检查未完约定与线索 | 发出一次工作台请求 |
| 规划下一步 | 结合现有任务给后续规划 | 不覆盖尚未完成的任务 |
| 让莉莉丝想一想 | 按当前表单请求建议 | 换人设后名字跟着替换 |
| 先看发送资料 | 展开本次计划发送的资料 | 预览本身不调用模型 |
| 查看当前任务 · 原账本只读 | 展开当前任务快照 | 不修改任务 |
| 本次发送的资料 | 展开实际请求背景 | 可以核对是否含你不想交给该接口的内容 |

**回信的处理。**「莉莉丝的回信」是可编辑建议草稿；「暂停自动接续」让下一轮不再自动承接这条建议；「旧方式：放入聊天输入框」把建议放到主输入框，由你发送；「往来记录」查看过去草稿。编辑草稿不代表任务已经执行，更不会因此到账奖励。

### 31.2 记忆契约的四个勾选

| 勾选项 | 打开后做什么 | 还需要什么 |
|---|---|---|
| 在当前聊天启用助手与记忆注入 | 启用该聊天的助手记忆工作 | 点保存当前聊天设置 |
| 正文结束后自动整理 | 每轮正文后最多一次独立整理请求 | 有可用记忆接口，会增加请求 |
| 下一轮正文自动承接记忆与工作台建议 | 向下一轮正文提供摘要与建议 | 不回头修改旧楼层 |
| 莉莉丝监管账本与奖励 | 允许助手核验最新数据块与账本 | 与启用项都保存后才能正常核验 |

「每轮提示预算 · 字符」决定传给正文的记忆提示长度，不是模型最大输出token设置。调整后按此页保存方式生效。

### 31.3 记忆页的每个按钮

| 按钮 | 作用 | 费用与影响 |
|---|---|---|
| 保存当前聊天设置 | 保存上面的启用、自动整理、接续、监管与预算 | 当前聊天；不是全局一键替所有聊天开启 |
| 立即核验最新正文（不请求模型） | 读取最新正文数据块，与账本核对并处理规则允许的结算 | 不调用AI；需要启用与监管已勾选并保存，不是纯查看按钮 |
| 整理最新回复 | 让模型提取最新回复的事实记忆 | 一次整理请求，成功后保存记忆 |
| 补读最近6条回复 | 补整理近期正文中的事实 | 不是创建6份游戏奖励；请求数量按当前整理流程 |
| 取消当前请求 | 中止当前助手请求 | 已保存数据不会因为取消自动回滚，服务商已处理的请求不保证免费 |
| 保存提醒 | 保存固定提醒文本 | 后续按记忆提示规则带给正文 |
| 查询已保存事实 | 用搜索框筛选人物、任务、物品等已存事实 | 不联网查、不额外调用模型 |
| 导出记忆与草稿备份 | 下载该助手保存的记忆与建议 | 不等于完整账本存档，要搬全部用导出存档 |

固定提醒适合写一直需要模型记住的事实，不适合填接口密钥。1.1.4起会清洗不安全、重复的记忆键，但模型输出没有通过其他校验时仍可能整理失败，不能因此承诺所有格式都能被接受。

### 31.4 规则页

「读取书目」读取酒馆世界书名单；选书后点「读取这本书」，将资料作为助手额外背景；「仅用内置规则」取消这份额外背景。它们不安装新书、不解绑诸天规则、不删除世界书文件。「查阅完整条目」输入任务、打手、盲盒等关键词搜索规则全文，通常是本地查阅，不是每次请求AI解释。

### 31.5 系统助手私聊窗口

点击助手立绘或头像上的私聊入口进入私聊。只有在助手窗口启用时提供这一套聊天；它与群员卡「私聊」不同。

| 按钮或控件 | 作用 | 保存和影响 |
|---|---|---|
| ↑ 发送私聊 | 发送输入内容，请求助手回复 | 保存到当前聊天的私聊记录，不改游戏账本 |
| Ctrl+Enter / ⌘+Enter | 与发送按钮相同 | 普通Enter用于换行，不自动发送 |
| 附带当前剧情 · 最近6条 | 给这次私聊提供最近剧情 | 不勾时不主动读取主剧情；勾上会把资料发送给私聊模型 |
| 陪我聊聊 | 用预置话题发起交流 | 属于私聊请求，不是新增任务 |
| 你在想什么？ | 用另一个预置话题交流 | 换人设时称呼跟着变 |
| ⌂ 返回工作台 | 回到助手工作台 | 保留已存私聊 |
| ⋯ 私聊菜单 | 展开复位、导出、清空按钮 | 展开不删数据 |
| × 收起私聊 | 收起这张私聊窗口 | 不删除记录 |
| 窗口复位 | 恢复私聊窗口大小与位置 | 不清空私聊 |
| 导出私聊 | 下载当前聊天的私聊JSON备份 | 与记忆备份和整份存档是不同文件 |
| 清空私聊 | 确认后删除当前聊天的助手私聊记录 | 不可直接撤销；不清事实记忆、主聊天或账本；请求中先停止 |

私聊里说“给我100万点”“完成任务”，只是对话，不是插件已经执行。出现“回复已显示但保存失败”时先复制可见回复，别把显示出来等同服务器保存成功。

## 32. 连接页 默认接口 预设和分功能接口

### 32.1 默认连接的所有字段

选择「单独的API」后填写接口地址、密钥和模型。地址一般用服务商提供的OpenAI兼容入口；不是任意聊天网页网址。模型名需与该接口实际支持的名称一致。选「直接用酒馆正在用的模型」后无需独立地址，但请求可能与主聊天生成互相等待。

| 按钮或字段 | 点后做什么 | 常见失败与处理 |
|---|---|---|
| 接口地址 | 设置请求发送到哪 | 错误路径、HTTP状态、跨域等需按服务商配置核对 |
| API 密钥 | 用于验证接口权限 | 密钥过期、额度不足、无权限等都会影响请求 |
| 模型 | 手动填或从列表选择 | 能拉模型不代表每个模型都能生成 |
| 拉取模型 | 请求接口的模型列表 | 接口不提供列表时可手填，失败不等于所有生成都不可用 |
| 测试连接 | 发小请求验证当前表单可用 | 会调用模型；不代表所有分功能已测或已保存 |
| 保存 | 保存当前连接到勾选的使用范围 | 测试通过仍应保存，否则可能继续使用旧配置 |
| 预设名称 | 最多24字，为接口取识别名 | 没名字时保存为预设按钮不可用 |
| 保存为预设 | 保存这一份地址、Key、模型及输出设置 | 可保留多套；上限30份；不等于所有功能都切到它 |
| 覆盖预设 | 输入已存在的预设名时，原「保存为预设」按钮改成此文字 | 覆盖该预设的配置；正在使用它的功能下一次请求用新配置 |
| 接口预设 下拉框 | 把所选预设载入表单 | 要设为默认还需点「保存」，只想给某个功能用则选分功能 |
| 删除 | 删除当前选中的预设，先确认 | 用该预设的功能改回跟随默认；不是删除主聊天 |
| 关闭 | 弹窗方式打开时关闭连接窗口 | 内嵌连接页没有同样的顶部关闭按钮 |

### 32.2 高级设置

「默认 / 预设最大输出」可填写64–65536 tokens，留空由各功能决定；不能超过模型和接口真实支持的上限，过大时服务商仍可能拒绝。思考模型也可能把推理算进预算。

「状态栏的 AI 功能」和「莉莉丝（私聊 / 记忆 / 工作台）」两个勾选决定这次保存更新哪套默认配置。只勾一个时，不要认为另一套也改好了。分功能覆盖可以让某个功能继续用不同模型，所以“我改了默认模型，为什么群聊没变”要检查分功能。

### 32.3 十二个分功能行

可分别设置商城进货、抽卡/盲盒、许愿、招募打手、背包整理/万物熔炉、战力评估、品阶鉴定、诸天聊天群、数据块补记、助手私聊、助手自动记忆、助手工作台。

每行下拉框选「跟随默认」、酒馆主API或已保存预设。每行「用上面填写的」将当前表单配置单独给这一项用；这不是只切换显示文字，也不是同时改12项。群员私聊、招募、世界书召唤等按聊天群的接口规则归组，但集市摆摊、挂单成交、普通降临扣账等本地操作不会仅因接口分组文字就都发AI请求。

### 32.4 下半部分 原版助手连接

「与莉莉丝建立连接」是助手自己的连接表单，含地址、Key、模型、最大输出长度。「拉取模型」读取可选模型；「保存连接配置」保存助手默认接口；「测试连接」验证这一套；「取消连接请求」取消正在进行的连接相关请求。上方统一连接与下方助手连接都可能影响助手默认值，改后核对真正生效的路由。

原版面板还保留一套「API连接设置」弹窗：齿轮打开，「获取模型」读取列表并显示可选模型，「测试连接」发测试请求，「保存设置」提交地址、密钥和模型，「关闭」收起弹窗。当前终端以统一连接页为主要入口，不必因为旧按钮名字不同就重新创建一套配置。

兼容助手的「莉莉丝等待契约唤醒」入口可以点击打开、按住拖动；其中“等待契约唤醒”是状态文字。无文字的图标按钮按悬停提示或无障碍名称识别，主终端的关闭、切换显示、设置等作用见第21章。

密钥不会写进正常导出存档和诊断报告，但会用于向你填写的接口认证。剧情、世界书片段、背包资料、记忆等会按功能发送给该接口；不要把“密钥不导出”误读成“AI功能完全不传数据”。

## 33. 所有设置项的作用范围和推荐检查方法

### 33.1 搜索 折叠和保存

「搜索设置」按设置名和说明过滤，空格分开的词一起匹配。清空搜索恢复全部。「进阶设置」「诊断与维护」点标题展开，搜索命中时可能自动展开。搜索不到一项时检查名称、当前版本，以及是否在单独的人设、开关、连接或群务页面。

开关、下拉框即时保存到酒馆扩展设置；页面提示“已交给酒馆保存”表示提交保存，不把它等同所有后端都已成功。存档环境不可保存时页面会给警告，处理后再改。

### 33.2 显示和手机

| 设置 | 打开或选中后 | 关闭或另一选项后 |
|---|---|---|
| 聊天楼层里的系统数据块 | 终端记账，小标签代替正文里的大面板 | 关闭时不自动处理正文数据块，手动终端操作仍可用 |
| 楼层小标签“系统已记录” | 楼层里有查看入口 | 标签隐藏；不因隐藏就删除账本 |
| 莉莉丝专属语音框 | 把系统台词美化成头像卡片 | 原文字照常显示；换人设按新名字识别 |
| 输入框上方账本速览 | 显示简短资产与任务，点击打开终端 | 速览隐藏，终端仍在 |
| 快捷键 | Alt+Z、Alt+X开关终端，Alt+S总览 | 需用其他入口 |
| 点击终端外部时关闭 | 仅手机、总是或从不 | 改的是外部点击，不是终端自身× |
| 手机上的终端与私聊窗口 | 自动手机全屏、总是全屏或浮动窗口 | 改布局，不改游戏数据 |
| 手机返回手势关闭终端 | 返回可关闭终端 | 关闭后返回行为交回宿主，按浏览器实际表现 |

### 33.3 提示词 世界书与超时

「旧楼层数据块不发给AI」只过滤本次生成用的副本，不擦掉聊天记录。「保留最新几层的数据块」可选0–6，默认2；0最省输入，但模型少了近层格式示例，格式稳定性要自己观察。世界书实时数据仍承担最新账本摘要。

「世界书变量宏」让规则中的变量表达式可读当前账本；有酒馆助手提供同类宏时会让位，不需要重复处理。「诸天存档自动安装并绑定世界书」不覆盖现有同名书，并会避开已启用书或已有其他聊天书等情形；关掉不会删除已装书。

「关闭插件时自动解绑世界书」在支持关闭钩子的宿主执行，1.16需手动解绑。「独立API超时」选60、120、180、300、600秒，默认180；给慢思考模型更多时间会等更久，不保证修好无权限、额度不足或错误地址。

### 33.4 助手样式和触摸

悬浮窗选自动、悬浮莉莉丝、头像、已关闭。**头像是仍然显示入口，已关闭才是全隐藏**。「关闭悬浮窗 ›」要确认；关闭后用扩展抽屉或快捷键回来。

大小选20%、30%、40%、55%、65%、75%、90%、100%。悬浮莉莉丝默认75%，头像默认100%；头像基准64像素，20%约13像素，点起来很小。尺寸改完立即更新，不重置位置。

「真实触摸互动」控制抚摸、长按和视线跟随；「触摸震动反馈」还要设备和浏览器支持震动。「界面角色反应」对选中任务、物品、功法和结算反馈；「进入系统页时说一句」每页每会话一次；「镜头」改变半身、全身、私聊特写；「气泡播报」显示数据块系统播报与部分点触台词。这些不是每次都额外请求模型。

### 33.5 世界 配色 演出和修行

界面主题自动跟随世界，或固定诸天、仙侠、赛博、诡异；配色可固定紫夜、墨金、青瓷、绯樱、霜蓝、赤霞、石墨，固定配色会覆盖主题颜色但保留装饰。世界类型识别错了去星图更正，不必修改全部角色资料。

「提示AI记录穿越」增加相关规则提醒，不能保证模型每次写对。「演出」选完整（最多2秒、可跳过）、仅结果卡或关闭；只在写入核对成功后展示已确认结果。「动态效果」自动、完整、精简，精简停掉一些动画，不减少功能。「预览演出」仅播样例，不改账本。「终端关闭时的剧情提示卡片」控制角落卡片，不关闭交易结算。

修行三个开关分别控制效果提示、实战漏记补积累、角色卡自动同步，默认角色卡自动同步是**关闭**，不要把1.1.5“模块默认开启”理解为全部细项都改为开。品阶两个开关控制收录提醒、明确更高品阶时对剧情功法的更正；更正只升不降，不能随意更改系统来源物品。

### 33.6 插件总开关

「一键关闭插件」确认后停用整个扩展并刷新页面，账本和设置仍保留；要恢复到酒馆「扩展 → 管理扩展」重新启用。它会连同终端入口一起停止，不要把它和“关闭悬浮窗”“隐藏一个页面”混为一谈。若开启自动解绑，还需注意世界书绑定的影响。

## 34. 数据块守卫 思维链保护和故障排查

### 34.1 每个开关和按钮

| 控件 | 实际动作 | 条件与恢复 |
|---|---|---|
| 自动修复新回复的数据块 | 修正本次新回复格式，保留修复前原文 | 不是给所有旧楼层批量重写 |
| 缺少数据块时自动补记 | 只在缺失时补一份，或关闭 | 打开可能额外请求一次；不对每个缺字段无限重试 |
| 每轮提醒AI数据块格式 | 每轮加格式规则提示，出错后更具体 | 关闭只停提醒，不自动关闭解析 |
| 格式提醒插入深度 | 1默认、0最末尾、2、4 | 与预填充冲突时优先试1，不能承诺兼容全部预设 |
| 剧情里学会功法但没入账时提示 | 检测可能漏记的功法并提示 | 提示本身不直接给宿主新增功法 |
| 去登记 | 从漏记提示进入剧情收纳 | 核对证据后人工确认 |
| 补记最新一层数据块 | 手动请求模型给最新无数据块回复补写 | 有数据块或不符合范围时不能当成重复领奖按钮 |
| 还原最新一次自动修复 | 恢复最近可还原楼层的原文 | 只还原改写，不是恢复全聊天、全账本历史 |
| 检查最新楼层：插件动过吗？ | 收集该层改写、渲染、思维链和扩展提示信息 | 用于归因；可能尝试复制结果，粘贴反馈前自行查看 |

### 34.2 思维链草稿为何变全角

模型可能在思维链里写未完成的数据块草稿，再在正文末尾写正式块。插件把思维链草稿标签变成全角，让解析器不误把草稿与正文的结束标签拼成一个块；思维链台词也不会再画成系统语音卡。

回复被截断、思维链未闭合时，守卫会跳过其他修复和补记；不能把跳过当成“已经完整修好”。正式块只在思维链里时按适用规则提取到正文后。旧楼层读取也会避开思维链草稿，但不等于批量擦改旧正文。

### 34.3 维护窗口里的每个按钮

| 按钮 | 用途 | 会不会改数据 |
|---|---|---|
| 兼容诊断 › | 检查宿主版本、规则书预算、旧组件、接口与环境 | 诊断本身主要只读 |
| 复制诊断信息 | 复制版本、设备、设置、近期错误等 | 自动遮挡密钥；不是替你向作者发送 |
| AI 接口设置 | 从诊断去连接页 | 打开不调用模型 |
| 重新渲染楼层 | 重建当前聊天的插件显示 | 不重新生成AI正文，不代替账本回滚 |
| 调整世界书预算 / 一键调整 | 提高酒馆世界书预算并按需处理预算上限 | 会改变酒馆预算设置；不是无限扩大模型上下文 |
| 核对并解冻账本 | 读取服务器与页面存档核对 | 不直接强制覆盖服务器账本 |
| 手机真机自检 | 开始屏幕、页面、键盘等引导检查 | 不买东西、不发游戏奖励 |
| 一键接管旧版 | 停用旧正则、旧脚本，保留恢复记录 | 不删除旧组件，但会改变启停状态 |
| 恢复旧版 | 恢复接管记录中的旧组件 | 不把当前扩展代码自动退回旧版 |

预算不足时，酒馆可能不把诸天常驻规则交给模型。调整预算后也要确保模型实际上下文够大；不能只增加百分比却超过接口真实支持长度。

### 34.4 解冻三种结果

“当前聊天没有被冻结”：可以正常操作，无需重复解冻。“服务器存档与页面一致，已解冻”：可以继续，先看上一笔是否已经到账再决定重做。“服务器存档与页面不一致”：会列出差异并询问重载；确认后按服务器存档恢复显示，先保存尚未发送的输入内容。

1.1.4缩小了核对范围，避免其他变量变化造成假失败，但真实保存错误仍可能冻结。跨标签页写入锁也取决于宿主与浏览器支持，不承诺任何浏览器、任何多窗口场景都绝无冲突。

### 34.5 手机自检的全部操作按钮

「跳过这一步」记录跳过当前检查，不记为通过；「结束自检」提前结束，结果里保留已经检查的项；「复制结果」复制简短结果；「复制完整诊断信息」复制环境与设置诊断；「关闭」关闭结果卡。浏览器不允许剪贴板时，用下面文字框长按全选复制。

部分步骤要亲手聚焦输入框弹键盘、旋转手机或按返回键，超时会记录警告或失败。自检不是插件已经在所有iOS和Android机型验收过的证据。

## 35. 存档 导入导出 回滚和世界书管理

### 35.1 完整存档导出

| 控件或按钮 | 操作 | 文件或结果 |
|---|---|---|
| 包含记忆存档（剧情记忆） | 勾选或取消 | 决定导出是否带助手事实记忆 |
| 包含莉莉丝私聊记录 | 勾选或取消 | 决定导出是否带助手私聊 |
| 导出存档文件 | 下载当前聊天账本与选定资料、可导出设置 | 不包含API密钥；每个聊天分别备份 |
| 复制存档文本 | 把同样的备份JSON复制到剪贴板 | 下载受阻时可另存文本；里面可能有私人剧情与私聊 |

想换设备，先导出对应聊天，再在新设备开目标聊天并导入。接口密钥单独配置，不应为了分享存档把密钥加进备注。备份会包含哪些资料取决于选项，不能用只含私聊的文件替代整份账本备份。

### 35.2 导入和预览

「选择存档文件…」选JSON文件；「粘贴存档文本…」显示文本框，粘贴完整存档。解析通过后出现现在与导入后的比较，包括来源版本、时间、聊天、账本与设置变化；这时尚未覆盖当前数据。

「写入账本和记忆」与「导入设置」可分别勾选。点「确认导入」，再次确认覆盖，先备份当前账本再执行。切换了聊天要重新预览；来自更高结构版本、损坏或不符合格式的文件会拒绝，不靠改文件扩展名就变合法。

导入后核对系统点、物品、当前世界、任务与助手记忆。旧设备的API密钥不会包含在文件里，导入不会用缺失的密钥把已有本地密钥全清空。仍需核对当前路由和模型是否可用。

### 35.3 迁移和回滚窗口

「旧存档迁移 / 账本回滚 ›」列出最近最多5份自动账本备份，带时间、原因、楼层和余额。「回滚到此」在确认后恢复对应账本；之后的新交易或进度可能被这次恢复覆盖，不只是回滚一条显示消息。

「重新导入旧助手配置」重新尝试读取旧版保存的助手连接等配置，之后刷新让窗口使用它；不是把旧聊天账本复制到当前聊天。没有旧配置时会提示，不自动编造。

### 35.4 世界书窗口的每个按钮

| 按钮 | 实际作用范围 | 关键限制 |
|---|---|---|
| 仅安装世界书 | 安装酒馆中缺失的诸天规则书 | 已有同名书不强制覆盖 |
| 安装并绑定到当前聊天 | 安装缺失书并绑定为当前聊天世界书 | 先打开单角色聊天；当前聊天原有世界书绑定需提前留意 |
| 更新到最新版（先备份） | 建一份备份书，再合并新内置规则 | 疑似自改条目逐项询问；取消该条覆盖会保留它 |
| 导出JSON | 导出插件内置最新诸天规则书 | 不是原样导出你修改过的当前安装书 |
| 一键解绑全部 | 解除所有角色卡、附加书、全局和当前打开聊天的诸天书绑定 | 不删除世界书；同时关闭自动绑定；其他未打开聊天的独立绑定不逐一处理 |
| 恢复上次解绑（范围） | 按上次记录恢复绑定 | 角色卡已删、已改绑别书等情况可能跳过 |
| 关闭 | 关闭管理弹窗 | 不撤销已执行安装、更新或解绑 |

换人设、从世界书召唤、群员读取资料不会改书文件；更新世界书、强力模块开关会改安装书；解绑只改绑定。理解这三种范围，才能判断更新或关闭功能会影响哪些聊天。

### 35.5 卸载和重装

先导出需要的每个聊天，记下接口地址和模型，再解绑世界书，最后在扩展管理中删除插件并刷新。删除扩展本身不删除保存在聊天文件的账本和助手记忆；重装后打开原聊天可以继续读取。若要回旧脚本，先按记录恢复，再避免新旧两套同时处理同一数据块。

## 36. 管理员面板的每个字段和按钮

入口「设置 → 进阶设置 → 高级·管理员 → 管理员控制台 ›」。这是直接改游戏存档的工具，不用模型，也不应把改出来的值当成正常任务奖励。先导出存档，改少量字段，核对确认列表后再写。

### 36.1 资产和专属资源

| 字段 | 作用与范围 |
|---|---|
| 系统点 | 当前可用于交易的点数，非负整数，不能填超出安全整数范围的数 |
| 子系统数量 | 0–999，修正记录数量，不自动创建这么多真实功能模块 |
| 子嗣数量 | 0–9999，修正记录，不自动生成对应剧情人物 |
| 当前货币 | 自由文本，如元、金币、灵石，不等于系统点 |
| 持有金额 | 自由文本，可保持原世界特殊金额表达 |
| 天命印记 | 修正猎艳相关专属资源计数 |
| 血脉结晶 | 修正多子多福相关专属资源计数 |
| 因果筹码 | 修正因果投资等专属资源计数，也用于禁忌获得代价 |
| 名望 | 修正名望计数，与普通商城折扣等关联 |
| 岁月沉淀 | 修正时间类专属资源计数，如洞天扩建所需 |

专属资源修改同时处理楼层快照中的相应差值，避免以后重新生成把管理员改动撤掉。资源仍是独立计数，不是修改系统点就连着增加全部专属资源。

### 36.2 实力 功法和盲盒

| 字段 | 范围与含义 |
|---|---|
| 宿主实力档 | 1–8，影响以宿主为基准的报价、概率或限制 |
| 本世界上限档 | 1–8，影响世界上限相关规则 |
| 商城等级下限 | 1–5，是商城等级的最低显示与规则值，不是直接选择商品品阶 |
| 主修功法 | 主修名称，与功法库同步；需终端原版引擎已加载 |
| 熟练度（当前值） | 非负整数，当前主修熟练度 |
| 上限（品阶上限） | 至少1，对应当前功法的上限记录 |
| 仙品保底计数 | 0–99，99表示下一抽到仙品保底 |
| 神品保底计数 | 0–999，999表示下一抽到神品保底 |
| 累计抽数 | 历史抽数记录，不单独代替当前两种保底计数 |
| 仙品次数 | 历史仙品出货次数 |
| 神品次数 | 历史神品出货次数 |

功法输入禁用时，先去「总览」加载系统引擎，再回管理员页重新读。只改累计抽数不应被解释成所有保底同步修改。字段留空表示不改，不是将原值清零。

### 36.3 羁绊 群员和动作按钮

「人物」下拉框选择具体人物，★表示当前攻略目标；可分别改好感度、黑化值、悔意值，范围0–100。「群员」下拉框选择具体群员，只改该成员好感0–100。切换人物或群员前有未保存改动，会提醒是否放弃。

| 按钮 | 执行动作 | 结果和风险 |
|---|---|---|
| 撤销改动 | 将当前表单恢复为读入时的值 | 不撤销已经保存到服务器的改动 |
| 重新读取 | 丢弃未保存表单，读取最新账本 | 适合页面提示存档已改变时用 |
| 写入账本 | 显示各项旧值→新值，确认后一次写入并核对 | 只写改过的项；冲突时停止，不盲目覆盖 |
| 打开原版面板 | 打开保留的旧式管理员编辑界面 | 字段比新面板少，使用旧式保存路径 |
| 真·写入变量 | 原版面板提交按钮 | 按原版面板字段执行，不等于新面板的改动预览 |
| 关闭 | 原版面板关闭按钮 | 未保存填写不生效，已保存值不会自动还原 |

新面板只有确实改了非空字段，才启用写入。写入前聊天被切换、待修改数据被别的操作改变等会拒绝并提示；重新读后再决定，不要在旧表单上反复提交。

## 37. 人设页面的所有字段和动作按钮

入口「设置 → 上手 → 系统助手人设 ›」。人设属于扩展设置，影响使用这份配置的聊天；换人设不清账本、背包和旧私聊。

### 37.1 预设与身份

| 控件 | 作用与填写要求 |
|---|---|
| 莉莉丝 | 默认原版人设和配套立绘，不启用非莉莉丝替换 |
| 系统光球（编号） | 选择冷静、简洁的编号系统，可修改名称、编号等 |
| 自定义 | 自写系统角色资料 |
| 名字 | 最多24字，非空至少2个非空白字符；光球留空用系统＋编号，自定义留空用系统助手 |
| 编号 | 光球才显示，最多8位字母数字，影响默认名称和光球图案 |
| 怎么称呼你 | 最多8字，默认宿主，不是更改酒馆用户账户名 |

头像存在扩展设置中，不生成公开图片链接；GIF经过裁切压缩后不承诺保留动图。上传读取失败或压缩后仍过大时会提示，不把失败头像当成已保存。

### 37.2 性格 高级替换和预览

「性格与人设」最多600字，描述身份、性格、关系；「说话方式」界面最多300字，写自称、语气、短句或长句等。光球留空用默认。

「高级：整段替换」展开后，剧情规则和私聊人设可各填最多4000字。留空按基本资料生成；填入后使用整段替换，请保留 `【名字】：“……”` 等台词格式、私聊不编造交易、不改账本等约束。整段规则也会附当前称呼对照，防止旧“莉莉丝”称呼带回旧人设。

「剧情规则（发给正文模型）」与「私聊人设（发给私聊模型）」展开查看当前草稿生成的提示。预览用来检查，不是发送按钮；检查完仍需保存。

### 37.3 页面底部四个动作

| 按钮 | 做什么 | 后果 |
|---|---|---|
| 保存并生效 | 校验草稿并保存人设 | 界面和之后的新请求使用新人设，一般不需刷新 |
| 放弃修改 | 回到已保存的人设资料 | 本次未保存输入被丢掉 |
| 换回莉莉丝 | 恢复莉莉丝预设 | 已保存的非莉莉丝状态会改变，旧剧情仍不重写 |
| 返回设置 | 丢弃本次未保存草稿并回设置页 | 想保留修改先点保存并生效 |

换新人设后，悬浮入口使用圆形头像，分层立绘与莉莉丝触摸不能变成一个新的完整动画角色。私聊、工作台和系统台词名字跟随替换；旧聊天、旧私聊正文不追溯修改。

当前规则中的其他莉莉丝称呼会机械替换，其中成人向内容也可能保留。换名字不等于自动清除全部原有人设背景；想彻底改规则，需要编辑高级替换，并自行检查其他规则条目是否也要调整。

| 输入框上方账本速览 | 隐藏输入框上方速览 |
| 快捷键Alt+Z / Alt+X / Alt+S | 停止这些快捷入口 |
| 斜杠命令/zt | 命令只提示已关闭，不执行对应动作 |
| 新手引导自动弹出 | 不自动弹引导，设置中仍可手动打开 |
| 世界主题（按当前世界换装饰） | 固定默认主题，不再按世界切装饰 |
| 演出（结算动画） | 停止结果演出，不停止游戏结算 |
| 终端关闭时的剧情提示卡片 | 停止对应角落卡片 |

### 38.6 其他按钮和按聊天设置

「系统助手人设 ›」跳到人设页；「返回设置」回普通设置；「搜索功能」按名称与说明筛选；清空搜索恢复列表。「全部开启」开启这张表的功能并恢复隐藏页面，可能把你有意停掉的功能也打开；不恢复已删除记录，不代替每个聊天自己的记忆、外挂和群聊开关，助手窗口仍需要刷新。

「终端页面」每行开关只把页面从导航拿掉，不是关闭那项后台功能。总览、设置、连接及恢复管理用的人设、开关页保留；聊天群与自拟模块关闭时，对应页面随模块关闭。

「按聊天的开关」三行「去设置」分别去记忆页、聊天群群务、外挂管理。记忆整理、群摘要与闲聊间隔、具体外挂启用都需要在对应聊天里设置，不会因为扩展级“全部开启”自动替所有存档改完。

## 39. 立绘 Live2D和分层PSD的设置说明

入口「设置 → 进阶设置 → 立绘 / Live2D 设置 ›」。Live2D指需要模型文件和渲染组件的真实动态立绘；原版分层动画不需要你提供这样的模型。

| 字段或按钮 | 用途与条件 |
|---|---|
| 模式 原版分层参数动画 | 使用随插件提供的分层莉莉丝 |
| 模式 AI差分立绘 | 使用表情或姿势差分；标素材待补的姿势暂回落标准站姿 |
| 模式 真Live2D | 使用你指定的Cubism模型；只选模式而不填有效模型不会自动生成 |
| 姿势 | 选择现有差分姿势，不是请求AI即时画图 |
| 表情跟随原版语气/点触 | 让差分按语气与点触切换 |
| 我已阅读并同意许可证 | 表明已阅读Live2D组件许可；实际使用仍按许可条件 |
| Cubism Core地址 | 加载渲染组件的地址；需要网络与宿主允许 |
| 模型.model3.json地址 | 你的模型入口，模型依赖的贴图等也需要可访问 |
| 缩放 | 0.2–4，控制立绘显示大小 |
| 水平偏移 | -1至1，调整左右位置 |
| 垂直偏移 | -1至1，调整上下位置 |
| 视线跟随鼠标 | 模型支持时让视线跟随 |
| 口型同步（TTS音量或文字节奏） | 用可用的声音或文字节奏驱动口型，不自动创建TTS服务 |
| 语气→模型表情 下拉框 | 将各类语气映射到模型已有表情 |
| 应用并加载 | 切换到真Live2D模式并尝试加载指定模型；各输入改动也按该页逻辑保存 |
| 导出莉莉丝分层PSD（供Cubism Editor绑定） | 导出带图层的绘画文件，供后续人工绑模型 |
| 关闭 | 退出配置弹窗，不撤销已应用配置 |

PSD是制作模型的原料，不是直接能播放的完整Live2D模型。导出成功不等于完成骨骼绑定；模型URL不可访问、资源缺失、许可未确认等按提示处理。当前莉莉丝真Live2D模型仍需人工绑定，其他人设默认用头像，不承诺套用莉莉丝整套动作。

## 40. 说明书 状态页 斜杠命令和完整故障处理

### 40.1 插件内说明书和这份网页版

插件左侧「说明书」读取随安装附带的 `docs/MANUAL.md` 快速版；本详细版作为单独在线文档提供，不把所有详细内容塞进聊天提示词。内置页的「搜索功能/按钮」按章过滤，多个词用空格分开；「目录」展开或收起，章节名点击跳转。搜索没有结果时换按钮原名或清空搜索。

本详细版网页另外有固定目录、搜索、清空搜索、打印、返回顶部和公告链接。它是阅读工具，不连接酒馆存档；在说明书里点章节和搜索不会发动插件功能。下载HTML后用浏览器打开即可离线阅读，不需要配置API。

网页顶部「搜索」按章节筛选内容，多个关键词用空格隔开；「清空」恢复40章；手机「目录」展开或收起目录，选章节后自动收起；「打印」打开浏览器打印，可选择另存PDF，并包含完整40章；「返回顶部 ↑」回页首。电脑按Ctrl+K，Mac按Command+K可聚焦搜索框；Esc关闭手机目录。长表格可横向滑动查看其余列。

状态页的「酒馆环境检测」「权限边界」「下一轮有效记忆提示」「工作台请求记录」用于看环境与将要发送的提示。看到提示内容不代表已经向模型成功发送，也不代表全部请求成功保存。

### 40.2 斜杠命令的操作范围

在主聊天输入框输入命令，并按酒馆命令方式执行。`/zt open`开终端，`/zt status`、`/zt shop`、`/zt bag`直接看总览、商城、背包；`/zt init`初始化或补齐账本；`/zt world`开世界书管理；`/zt backup`开迁移回滚；`/zt export`开存档导入导出；`/zt diag`开兼容诊断；`/zt copydiag`复制诊断；`/zt selftest`手机自检；`/zt points`返回当前系统点；`/zt live2d`切真Live2D，`/zt live2d off`切回分层模式。

命令打开页面不代替该页面的确认按钮。`/zt init`会写缺失数据，`/zt points`只是读数字；`/zt live2d`仍需要事先配置可用模型，不会自动提供模型文件。

### 40.3 常见问题按症状处理

| 症状 | 先检查什么 | 下一步 |
|---|---|---|
| 更新后看起来还是旧版 | 是否在扩展管理真正更新，还是只刷新 | 更新完成后刷新，复制诊断核对版本和修订 |
| 悬浮窗不见了 | 是关闭、藏到边缘、换人设还是插件停用 | 用扩展抽屉显示头像，或重新启用插件 |
| 页面不见了 | 功能开关里的终端页面、模块、助手窗口 | 恢复需要的项，助手窗口改动后刷新 |
| 提示没有诸天账本 | 是否打开单角色聊天并初始化 | 新聊天初始化，或导入该聊天备份 |
| 主AI不承认交易 | 是否保存成功、实时摘要是否正确、操作摘要是否发送 | 核对账本后发已完成摘要，别再重复扣费 |
| 抽卡后背包没多 | 奖励是否仍在待处理 | 保留或全部保留；不重复抽同一笔 |
| 群员记忆正文里没表现 | 成员是否世界书来源、关键词是否命中、两个注入开关是否开 | 核对提示与来源；模型扮演效果仍需真实模型观察 |
| 群聊只回半句 | 输出预算与人数、字数、路由上限 | 调整后重roll，已领取奖励的轮次不能重来 |
| API测试好但某功能失败 | 该功能是否单独路由到另一预设 | 检查分功能路由、支持模型、输出格式与费用额度 |
| 请求很慢或超时 | 接口服务状态、主聊天是否忙、超时预算 | 合理增大超时，减少携带资料，按错误码处理 |
| 思维链标签异常 | 最新楼层检查、其他扩展、预设和世界书深度 | 依据报告定位，不一概归咎某一插件 |
| 保存失败或冻结 | 页面与服务器是否一致 | 核对解冻，必要时重载或从备份恢复 |
| 手机输入框被遮挡 | 全屏/浮窗、键盘可见区域、浏览器模式 | 先手机自检并复制结果反馈 |
